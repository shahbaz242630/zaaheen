# Contributing

Thank you for your interest in Zaaheen. We are not taking code contributions at the moment, so please do not open pull requests.

If you want to reach us:

- **Help with the app:** see the [troubleshooting guide](https://zaaheen.com/docs/troubleshooting/), or email [customerservice@zaaheen.com](mailto:customerservice@zaaheen.com).
- **A security problem:** report it privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue.
- **Anything else:** email [customerservice@zaaheen.com](mailto:customerservice@zaaheen.com).

The code in this repository is published so that anyone can review how Zaaheen handles their memories. It is not open source; see [LICENSE](LICENSE).
