Questions fréquentes

Les questions qu’on nous pose sur Zaaheen.

Que fait Zaaheen ?

Zaaheen donne à vos applications d’IA une mémoire unique et partagée à votre sujet. Dites quelque chose une fois à Claude, Cursor, ChatGPT, Claude Code, Codex et Antigravity, et toutes les applications que vous connectez pourront s’en souvenir ensuite. Zaaheen fonctionne sur votre PC Windows ou votre Mac et y garde vos souvenirs, chiffrés.

Pourquoi choisir Zaaheen plutôt qu’un autre outil de mémoire pour l’IA ?

Zaaheen réunit trois choses. Vos souvenirs restent sur votre propre ordinateur, chiffrés, et nos serveurs ne les reçoivent jamais. Une seule mémoire fonctionne avec toutes vos applications d’IA connectées, au lieu d’une mémoire séparée dans chacune. Et vous gardez la main : vous voyez chaque souvenir, vous oubliez celui que vous voulez, vous les téléchargez tous ou vous supprimez tout en une étape. Zaaheen coûte 5 USD par mois ou 48 USD par an après un essai gratuit de 30 jours, sans carte. Notre page Tarifs le compare avec d’autres outils de mémoire, vérifiés sur le site de chaque entreprise. Comparer Zaaheen avec d’autres outils de mémoire.

Où Zaaheen garde-t-il mes souvenirs ?

Sur votre propre ordinateur, chiffrés, et ils ne sont jamais envoyés en ligne. Vous pouvez les déplacer vers un autre dossier ou un autre disque depuis Settings, avec Move my memories.

Puis-je voir et supprimer ce dont mes applications d’IA se souviennent à mon sujet ?

Oui. Chaque souvenir figure dans l’application Zaaheen, où vous pouvez le rechercher ou oublier celui que vous voulez. Delete everything, dans Settings, détruit la clé de chiffrement et les fichiers de mémoire en une étape.

Ai-je besoin d’un compte pour utiliser Zaaheen ?

Oui. Vous créez un compte ou vous vous connectez la première fois que vous ouvrez l’application, et cette première connexion depuis l’application lance votre essai gratuit de 30 jours. Le compte sert à la connexion et à votre abonnement. Il ne contient jamais vos souvenirs.

Dois-je savoir ce qu’est MCP ?

Non. MCP est la façon standard dont les applications d’IA se connectent à des outils, et l’application Zaaheen connecte Claude, Cursor, ChatGPT, Claude Code, Codex et Antigravity pour vous. Pour les autres applications d’IA compatibles MCP, la page Documentation explique comment faire. Comment connecter vos applications d’IA.

Claude Code se souvient-il de choses d’une session à l’autre ?

Claude Code garde des notes pour chaque projet dans des fichiers comme CLAUDE.md. Connectez-le une fois à Zaaheen, avec une seule commande, et il pourra aussi enregistrer ce qu’il apprend sur vous et votre façon de travailler, puis s’en souvenir dans toutes les sessions suivantes et dans tous vos projets. Vos autres applications d’IA connectées partagent les mêmes souvenirs. Claude Code se souvient-il d’une session à l’autre ?.

Cursor se souvient-il de moi d’un chat à l’autre ?

Oui, une fois Cursor connecté à Zaaheen. Il peut enregistrer ce qu’il apprend sur vous pendant que vous travaillez et le retrouver dans n’importe quel chat ou projet suivant. Cursor consulte Zaaheen de lui-même quand vous lui posez une question sur vous. Connecter Cursor.

Puis-je utiliser une seule mémoire avec Claude Code, Cursor et Codex ?

Oui. Connectez chacun d’eux une fois à Zaaheen, et ils liront et enregistreront tous dans la même mémoire sur votre ordinateur. Une préférence que vous donnez à Claude Code sera là quand vous ouvrirez Cursor ou Codex. Une seule mémoire pour Claude Code, Cursor et Codex.

Comment passer de ChatGPT à Claude sans perdre le contexte ?

Connectez les deux à Zaaheen. Ce que vous dites à l’une ou l’autre application va dans une seule mémoire sur votre ordinateur, donc l’autre peut s’en souvenir quand vous changez. La mémoire intégrée de chaque application ne s’importe pas encore en un clic : demandez donc à l’application que vous utilisiez d’enregistrer l’essentiel dans Zaaheen. Comment partager la mémoire entre ChatGPT et Claude.

Qu’est-ce qu’un serveur de mémoire MCP ?

MCP est la façon standard dont les applications d’IA se connectent à des outils. Un serveur de mémoire est un outil qui donne aux applications d’IA un endroit où enregistrer des faits sur vous et les retrouver plus tard. Zaaheen en est un : il fonctionne sur votre propre ordinateur et permet aux applications connectées de lire, rechercher, enregistrer, corriger et oublier des souvenirs. Comment connecter vos applications d’IA.

ChatGPT fonctionne-t-il avec Zaaheen ?

Oui, l’application ChatGPT pour votre ordinateur. Ajoutez Zaaheen dans les réglages de ChatGPT, sous Plugins, puis MCP, et utilisez-le dans un chat Work ou Codex. Le mode Chat de ChatGPT, et ChatGPT dans un navigateur web, ne peuvent pas se connecter aux applications de votre ordinateur. Connecter ChatGPT.

Zaaheen utilise-t-il lui-même l’IA ?

Oui, trois petits modèles d’IA qui fonctionnent sur votre propre ordinateur : l’un comprend le sens, un autre classe les résultats et le troisième fait le ménage. Une fois téléchargés, ils fonctionnent hors ligne, et vos souvenirs ne passent jamais par un service d’IA en ligne. Zaaheen transmet à vos applications d’IA les souvenirs qui correspondent, tels qu’ils sont enregistrés, et c’est l’application que vous utilisez qui rédige la réponse.

À quoi sert le rangement ?

Il fusionne les souvenirs presque identiques, tranche les faits qui se contredisent en faveur du plus récent et retire du rappel quotidien les souvenirs que vous n’utilisez jamais. Il ne supprime jamais un souvenir. La configuration l’active, chaque jour à 3 h du matin, sauf si vous choisissez Not now, et vous pouvez le modifier ou le désactiver dans Consolidation. Ce dont il a besoin, environ 2,5 Go, se télécharge une seule fois pendant la configuration.
