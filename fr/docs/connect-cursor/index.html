Comment connecter Cursor à Zaaheen

Dans Zaaheen, ouvrez l’onglet Agents, choisissez Connect an app, puis Cursor Desktop et Connect it for me. Cursor s’ouvre et vous demande d’installer Zaaheen, ce qui peut prendre jusqu’à une minute : cliquez sur Install. L’IDE Cursor utilise ensuite la même connexion.

Vous utilisez l’IDE Cursor ? Connectez Zaaheen ici, via Cursor Desktop : l’IDE n’a pas de réglages MCP à lui et utilise ceux de Cursor Desktop, donc une seule connexion suffit pour les deux.

Suivez bien les deux étapes. Si vous en sautez une, Cursor Desktop risque de ne pas utiliser Zaaheen.

Étape 1A : la méthode rapide

Zaaheen › Agents

Zaaheen ouvre Cursor, et Cursor vous demande d’installer Zaaheen. Cursor peut mettre jusqu’à une minute pour s’ouvrir et afficher sa fenêtre Install : attendez-la, puis cliquez sur Install.

  1. Dans Zaaheen, ouvrez l’onglet Agents et choisissez Connect an app.
  2. Choisissez Cursor Desktop, puis Connect it for me.
  3. En attente de l’ouverture de Cursor et de sa fenêtre Install. Cela peut prendre jusqu’à une minute.
  4. Cursor devrait maintenant afficher sa fenêtre Install. Cliquez sur Install : c’est connecté. Si rien n’apparaît, passez à la fenêtre de Cursor : la fenêtre Install est peut-être derrière celle-ci.

Étape 1B : ou ajoutez-le vous-même

Cursor › Customize

Le plus simple pour avoir le bon réglage : dans Zaaheen, ouvrez Agents, choisissez Connect an app, puis Cursor Desktop. Le réglage s’affiche avec le chemin propre à cet ordinateur, et un bouton Copy. Utilisez les boutons de copie plutôt que de sélectionner le texte à la main.

Le chemin ci-dessous est un exemple. Il ressemblera à C:\Program Files\Zaaheen\zaaheen.exe, l’emplacement où Zaaheen s’installe habituellement sous Windows. Si vous avez installé Zaaheen ailleurs, par exemple sur un autre disque ou dans un autre dossier, votre chemin est différent et celui-ci ne fonctionnera pas. Copiez votre chemin exact depuis Zaaheen : Agents, Connect an app, Cursor Desktop, puis Copy.

Dans Cursor Desktop, choisissez Customize dans la barre de gauche, puis MCPs. Descendez tout en bas, choisissez + New MCP server et collez-y ceci. Enregistrez :

{
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

Le chemin ci-dessous est un exemple. Il ressemblera à /Applications/Zaaheen.app/Contents/MacOS/zaaheen, l’emplacement où Zaaheen s’installe habituellement sur un Mac. Si vous avez installé Zaaheen ailleurs, votre chemin est différent et celui-ci ne fonctionnera pas. Copiez votre chemin exact depuis Zaaheen : Agents, Connect an app, Cursor Desktop, puis Copy.

Dans Cursor Desktop, choisissez Customize dans la barre de gauche, puis MCPs. Descendez tout en bas, choisissez + New MCP server et collez-y ceci. Enregistrez :

{
  "mcpServers": {
    "zaaheen": {
      "command": "/Applications/Zaaheen.app/Contents/MacOS/zaaheen",
      "args": ["mcp", "serve"]
    }
  }
}

Étape 2 : vérifiez que c’est connecté

Cursor › Customize

Dans Cursor Desktop, choisissez Customize dans la barre de gauche, puis MCPs. zaaheen y figure et il est connecté.
