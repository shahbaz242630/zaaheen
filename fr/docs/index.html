Bien démarrer

Comment installer Zaaheen

Windows ou Mac

Zaaheen 0.3.6 est disponible pour Windows (64 bits, testé sur Windows 11) et pour les Mac avec puce Apple, M1 ou plus récent (testé sur macOS 26). Il n’est pas encore disponible pour Linux ni pour les téléphones.

Télécharger pour Windows Télécharger pour Mac

Sous Windows, ouvrez le programme d’installation (149 Mo). Sur un Mac, ouvrez l’image disque (154 Mo), faites glisser Zaaheen dans le dossier Applications et ouvrez-le depuis cet endroit. Windows ou votre Mac peuvent vous poser une ou deux questions en chemin, et c’est normal : ce que signifie chaque question et quoi choisir.

Ce qui se passe à la première ouverture

Configuration

Choisissez Begin set up. La configuration prend environ trois minutes :

  1. Votre compte. Choisissez Create an account ou Sign in. Votre navigateur web s’ouvre. Votre essai gratuit de 30 jours commence la première fois que vous vous connectez depuis l’application Zaaheen, et aucune carte n’est demandée. Vous connecter ne nous transmet jamais vos souvenirs.
  2. Où garder vos souvenirs. L’emplacement habituel convient à la plupart des gens. Vous pourrez le changer plus tard.
  3. Votre première application d’IA. Choisissez l’application que vous utilisez et suivez les étapes, ou choisissez I'll connect one later.
  4. Votre premier souvenir. Dites à Zaaheen quelque chose que vos applications d’IA devraient savoir sur vous, puis choisissez Keep this memory, ou Skip for now.
  5. Le rangement. Choisissez si Zaaheen range votre mémoire de lui-même chaque jour, puis Finish setup.

La première fois, Zaaheen télécharge aussi ce dont il a besoin pour rechercher dans vos souvenirs. Il le fait en arrière-plan, et vous pouvez l’utiliser pendant ce temps. Guide complet : installer et configurer Zaaheen.

Connecter vos applications d’IA

Ouvrez l’onglet Agents et choisissez + Connect an AI app. Zaaheen ne modifie jamais lui-même les réglages d’une autre application : il donne à l’application ce dont elle a besoin, et c’est l’application qui vous le demande.

Claude Desktop (l’application Claude pour votre ordinateur)

Agents › Connect

Choisissez Connect it for me. Claude vous demande d’installer Zaaheen : cliquez sur Install, et c’est connecté. Cela fonctionne dans Chat et Cowork de Claude. Guide complet : connecter Claude Desktop.

Claude Code (Claude dans votre terminal)

Terminal

Dans un terminal, exécutez une fois la commande affichée dans l’onglet Agents. Zaaheen est ensuite disponible dans tous vos projets Claude Code. Guide complet : connecter Claude Code.

Cursor

Agents › Connect

Choisissez Connect it for me. Cursor vous demande d’installer Zaaheen : cliquez sur Install, et c’est connecté. Guide complet : connecter Cursor.

ChatGPT (l’application pour votre ordinateur)

ChatGPT › Settings

Dans ChatGPT, ouvrez Settings, puis Plugins, puis MCP, et ajoutez Zaaheen comme serveur MCP. Utilisez-le dans le mode Work ou Codex de ChatGPT ; son mode Chat ne peut pas se connecter aux applications de votre ordinateur. Guide complet : connecter ChatGPT.

Autres applications d’IA

Agents

Zaaheen se connecte via MCP, le standard qu’utilisent de nombreuses applications d’IA. L’onglet Agents affiche aussi le réglage pour les autres applications. Une application apparaît dans cet onglet tant qu’elle est ouverte et connectée. Guide complet : connecter d’autres applications d’IA.

Vos souvenirs

Où sont gardés vos souvenirs

Settings › Your memories

Sur votre propre ordinateur, chiffrés. Ils ne sont jamais envoyés en ligne. Pour les garder dans un autre dossier ou sur un autre disque, choisissez Move my memories…. Zaaheen se ferme, les déplace et se rouvre tout seul. S’il se ferme en cours de route, vos souvenirs restent en sécurité là où ils étaient.

À quoi sert le rangement (consolidation)

Consolidation

Pendant votre absence, Zaaheen organise ce qu’il a appris : il fusionne les doublons proches en un seul souvenir, tranche les faits qui se contredisent en faveur du plus récent et archive hors du rappel quotidien les anciens souvenirs que vous n’utilisez jamais. Il ne les supprime jamais, et tout se passe sur votre ordinateur.

La configuration l’active, chaque jour à 3 h du matin, sauf si vous choisissez Not now. Vous pouvez le modifier ou le désactiver dans Consolidation. Si votre ordinateur était en veille ou éteint à cette heure-là, il rattrape plus tard. Pour ranger tout de suite, choisissez Run consolidation now. Zaaheen télécharge ce dont il a besoin, environ 2,5 Go, une seule fois, pendant la configuration.

Comment emporter vos souvenirs

Settings › Your memories

Choisissez Download my memories. Tout ce que vous avez gardé est enregistré dans un seul fichier. Il vous appartient, que vous soyez abonné ou non : le bouton reste disponible même après la fin d’un essai ou d’un abonnement.

Comment annuler une suppression ou une modification

Memories › Recently deleted

Quand vous ou une application d’IA supprimez ou modifiez un souvenir, la version précédente attend 30 jours dans Recently deleted. Ouvrez-la depuis le lien au-dessus de votre liste de souvenirs, puis choisissez restore pour récupérer un souvenir. delete now en efface un tout de suite, et Empty Recently deleted les efface tous. Après 30 jours, ils sont effacés pour de bon. Vous seul voyez cette liste : les applications d’IA ne peuvent pas l’ouvrir.

Ensemble, les applications d’IA peuvent supprimer ou modifier au plus 30 souvenirs par heure. Ensuite, Zaaheen leur demande de faire une pause, et vous pouvez toujours supprimer ou modifier ce que vous voulez dans l’application.

Comment tout supprimer

Settings › Your memories

Choisissez Delete everything, tapez DELETE pour confirmer, puis choisissez Permanently delete everything. Cela détruit la clé de chiffrement et les fichiers de mémoire : c’est irréversible, et aucune copie chiffrée ne pourra plus être déverrouillée. Les fichiers enregistrés avec Download my memories sont des copies lisibles qui ne sont pas concernées : supprimez-les vous-même. Supprimer vos souvenirs ne résilie pas votre abonnement ; résiliez-le séparément avec Cancel subscription.

Compte et abonnement

Comment fonctionnent l’essai et l’abonnement

Settings › Account

Les 30 premiers jours sont gratuits, sans carte. Ensuite, c’est 5 USD par mois ou 48 USD par an. Pour vous abonner, choisissez Subscribe dans l’application : le paiement s’ouvre dans votre navigateur, et Zaaheen se débloque tout seul une fois le paiement passé. Pour changer de formule ou mettre à jour votre carte, choisissez Manage subscription. Pour l’arrêter, choisissez Cancel subscription. Les deux se trouvent aussi sur votre page Account sur zaaheen.com. Vous pouvez aussi utiliser le lien de résiliation présent dans chaque e-mail de Paddle, notre revendeur, qui fonctionne depuis n’importe quel appareil.

À la fin d’un essai ou d’un abonnement, rien n’est supprimé. Tout reste sur votre ordinateur, et vous pouvez toujours le télécharger.

Comment supprimer votre compte

Settings › Account

Choisissez Delete my account dans l’application. Elle propose de télécharger vos souvenirs, supprime les souvenirs de cet ordinateur, puis ouvre une page où vous confirmez la suppression de votre compte Zaaheen. Pour supprimer uniquement votre compte et garder vos souvenirs, utilisez plutôt la page Delete my account de notre site.

Supprimer votre compte résilie aussitôt tout abonnement, sans remboursement du temps restant. Si vous avez payé au cours des 14 derniers jours, demandez d’abord votre remboursement selon notre Politique de remboursement (en anglais).

Comment désinstaller Zaaheen

Paramètres Windows ou Applications

Désinstaller l’application ne supprime pas vos souvenirs : une réinstallation les retrouve. Pour supprimer aussi vos souvenirs, utilisez d’abord Delete everything.

Sous Windows, ouvrez les Paramètres de Windows, puis Applications, puis Applications installées, et désinstallez Zaaheen.

Sur un Mac, quittez Zaaheen, puis faites-le glisser d’Applications vers la Corbeille. Pour libérer l’espace qu’utilisent ses moteurs d’IA téléchargés (plusieurs Go), supprimez aussi les dossiers ~/Library/Application Support/com.zaaheen.app et ~/Library/Logs/com.zaaheen.app.

Aide

Comment obtenir de l’aide

Settings › Help

Écrivez à customerservice@zaaheen.com. Si quelque chose ne s’est pas bien passé, choisissez Save activity record… et joignez le fichier. Ce journal ne contient aucun de vos souvenirs. Beaucoup de problèmes se règlent vite grâce à Résoudre les problèmes courants.
