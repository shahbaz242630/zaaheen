Comment installer et configurer Zaaheen

Téléchargez Zaaheen pour Windows ou Mac et installez-le, puis choisissez Begin set up. La configuration prend environ trois minutes : vous vous connectez depuis l’application, ce qui lance votre essai gratuit de 30 jours (sans carte), vous choisissez où garder vos souvenirs et vous connectez votre première application d’IA. L’application est en anglais.

Avant de commencer

Windows ou Mac

Zaaheen 0.3.8 est disponible pour Windows 64 bits, testé sur Windows 11, et pour les Mac avec puce Apple, M1 ou plus récent, testé sur macOS 26. Il n’est pas encore disponible pour Linux ni pour les téléphones.

Télécharger pour Windows Télécharger pour Mac

Installer

Windows ou Mac

Sous Windows, ouvrez le programme d’installation que vous avez téléchargé. Jusqu’à trois questions peuvent s’afficher en chemin, et c’est normal :

  • Microsoft Edge indique que le fichier « isn't commonly downloaded ». Le programme d’installation est récent, Edge ne l’a donc pas encore vu souvent. Choisissez les trois points à côté du téléchargement, puis Keep, Show more et Keep anyway. Chrome ne pose pas la question.
  • Windows indique que l’éditeur est inconnu. Le programme d’installation n’est pas encore signé ; la signature viendra plus tard. Choisissez More info, puis Run anyway.
  • Windows demande l’autorisation d’administrateur. Zaaheen s’installe pour tous les utilisateurs de l’ordinateur, Windows le demande donc une fois. Il n’a pas besoin des droits d’administrateur pour fonctionner ensuite.

Sur un Mac, ouvrez l’image disque que vous avez téléchargée, faites glisser Zaaheen dans le dossier Applications, puis ouvrez Zaaheen depuis Applications. Zaaheen ne fonctionne que depuis cet endroit.

  • Votre Mac demande s’il faut ouvrir une application téléchargée sur internet. Il indique le nom du développeur. L’application Mac est signée et vérifiée par Apple. Choisissez Open.
  • Votre Mac peut demander si Zaaheen a le droit d’utiliser votre trousseau. C’est là qu’est gardée la clé de vos souvenirs. Choisissez Always Allow.

Pour vérifier votre téléchargement, comparez son empreinte (SHA-256) avec celle ci-dessous. Si elles diffèrent, supprimez le fichier et téléchargez-le à nouveau depuis ce site.

  • Windows (Zaaheen_0.3.8_x64.msi) : 50147fc643b9e8d4e743c60acbd5c21a34e6672d211534d7add288f28c20d0e4. Dans PowerShell, exécutez Get-FileHash "$HOME\Downloads\Zaaheen_0.3.8_x64.msi".
  • Mac (Zaaheen_0.3.8_aarch64.dmg) : ae694d3d02ef0d38b591c70db3b4710673f3549c5c9a0d6956d145ce39ed12ab. Dans Terminal, exécutez shasum -a 256 ~/Downloads/Zaaheen_0.3.8_aarch64.dmg.

Configurer

Begin set up

Ouvrez Zaaheen et choisissez Begin set up. L’application vous guide en cinq étapes :

  1. Votre compte. Choisissez Create an account ou Sign in. Votre navigateur web s’ouvre. Votre essai gratuit de 30 jours commence la première fois que vous vous connectez depuis l’application Zaaheen, et aucune carte n’est demandée. Vous connecter ne nous transmet jamais vos souvenirs.
  2. Où garder vos souvenirs. L’emplacement habituel convient à la plupart des gens. Vous pourrez le changer plus tard depuis Settings, avec Move my memories….
  3. Votre première application d’IA. Choisissez l’application que vous utilisez et suivez les étapes, ou choisissez I'll connect one later.
  4. Votre premier souvenir. Dites à Zaaheen quelque chose que vos applications d’IA devraient savoir sur vous, puis choisissez Keep this memory, ou Skip for now.
  5. Le rangement. Zaaheen range votre mémoire de lui-même chaque nuit, sauf si vous choisissez Not now, puis Finish setup.

La première fois, Zaaheen télécharge aussi ce dont il a besoin pour rechercher dans vos souvenirs. Il le fait en arrière-plan, et vous pouvez utiliser Zaaheen pendant ce temps.

Et ensuite

Agents

Connectez les applications d’IA que vous utilisez, chacune une fois, depuis l’onglet Agents :

  • Connecter Claude Desktop
  • Connecter Claude Code
  • Connecter Cursor
  • Connecter ChatGPT
  • Connecter Codex
  • Connecter Antigravity
  • Connecter d’autres applications d’IA

Si quelque chose ne fonctionne pas comme décrit, consultez Résoudre les problèmes courants.
