Résoudre les problèmes courants avec Zaaheen

La plupart des problèmes viennent d’une application d’IA qui ne regarde que dans sa propre mémoire, ou qui n’est pas encore connectée. Chaque solution ci-dessous commence par la réponse. Si votre problème n’y est pas, contactez-nous avec un journal d’activité depuis Settings.

Messages d’erreur et solutions

Toutes les applications

Trouvez les mots que vous voyez, puis faites ce qui est indiqué à côté. Les messages sont en anglais, tels qu’ils s’affichent.

Invalid result for tools/call: missing required resultType Claude Code, quand il appelle Zaaheen
Mettez Zaaheen à jour avec la dernière version sur zaaheen.com : les versions 0.3.1 et suivantes répondent correctement aux applications les plus récentes.
The filename, directory name, or volume label syntax is incorrect. (os error 123) ChatGPT Desktop ou Codex, dans le journal de l’application ; ChatGPT indique seulement que Zaaheen n’est pas accessible
Le champ Command contient un espace ou des guillemets avant C:. Modifiez le serveur MCP pour que Command commence exactement par C:\ (copiez-le avec le bouton Copy de l’onglet Agents de Zaaheen), enregistrez, puis redémarrez ChatGPT.
Zaaheen isn't accessible in this chat ChatGPT Desktop
Utilisez un chat Work ou Codex (le mode Chat de ChatGPT ne peut pas se connecter aux applications de votre ordinateur), vérifiez que Command n’est précédé d’aucun espace, puis quittez complètement ChatGPT et rouvrez-le.
request timed out (zaaheen: Tools: (none)) Codex dans le terminal, après /mcp
Mettez Codex à jour (npm install -g @openai/codex@latest), puis relancez codex et tapez /mcp : zaaheen apparaît comme connecté, avec 6 outils.
L’application d’IA enregistre dans sa propre mémoire, ou répond « I don't know », au lieu d’utiliser Zaaheen Claude Desktop, ChatGPT Desktop, Codex
Ajoutez la ligne de Zaaheen aux instructions de l’application (Claude : Settings, Account, Instructions for Claude ; ChatGPT : Custom instructions ; Codex : AGENTS.md dans le dossier .codex). La ligne se trouve sur cette page et dans chaque guide de connexion.
Un double-clic sur « Zaaheen for Claude.mcpb » demande avec quelle application l’ouvrir Windows, avec Claude installé depuis le Microsoft Store
Annulez cette fenêtre. Dans Claude, ouvrez Settings, puis Extensions, puis Advanced settings, puis Install Extension, et choisissez « Zaaheen for Claude.mcpb ».
isn't commonly downloaded. Make sure you trust [the Zaaheen installer] before you open it. Microsoft Edge, au téléchargement
Choisissez les trois points à côté du téléchargement, puis Keep, puis Show more, puis Keep anyway. Le programme d’installation est récent et pas encore signé, Edge ne l’a donc pas vu souvent.
Windows protected your PC. Microsoft Defender SmartScreen prevented an unrecognized app from starting. Windows, à l’ouverture du programme d’installation
Choisissez More info, puis Run anyway.
Your memories were NOT deleted, and they are still readable. Mac, après Delete everything ou Delete my account dans Zaaheen 0.3.0
Mettez Zaaheen à jour avec la dernière version sur zaaheen.com (0.3.1 ou plus récente), puis réessayez. Rien n’a été supprimé, et votre compte et votre abonnement n’ont pas changé.
Still working. This is taking longer than usual. Please keep Zaaheen open. Mac, pendant Delete everything ou Delete my account
macOS pose peut-être une question sur Zaaheen et votre trousseau dans une fenêtre cachée derrière celle de Zaaheen : cherchez-la et choisissez Allow. La suppression se termine alors. Rien n’est supprimé tant que votre clé n’a pas disparu : si vous fermez Zaaheen à la place, vos souvenirs sont toujours là et vous pouvez réessayer.
This site can't be reached Votre navigateur, juste après la connexion depuis l’application Zaaheen (ou une autre erreur du navigateur à ce moment-là)
Revenez dans l’application Zaaheen : elle indique si vous êtes connecté. La page qui suit la connexion ne fait que la confirmer, peu importe donc si elle ne s’est pas chargée.
Zaaheen has paused deletes and edits from AI apps for a while, to protect your memories. You can delete or edit them in the Zaaheen app. Toute application d’IA, après avoir supprimé ou modifié beaucoup de souvenirs
Rien d’anormal. Ensemble, vos applications d’IA peuvent supprimer ou modifier 30 souvenirs par heure, et la pause se lève en moins d’une heure. Pour supprimer ou modifier davantage tout de suite, faites-le vous-même dans l’application Zaaheen. Tout ce qui a été supprimé ou modifié reste 30 jours dans Memories, Recently deleted.

Mon application d’IA répond sans utiliser Zaaheen

Claude, ChatGPT, Codex

Claude, ChatGPT et Codex regardent d’abord dans leur propre mémoire et peuvent s’arrêter là, ou y enregistrer. Ajoutez cette ligne aux Instructions for Claude de Claude (Settings, puis Account), aux Custom instructions de ChatGPT, ou au fichier AGENTS.md du dossier .codex de Codex, et ils enregistreront aussi dans Zaaheen et le consulteront. La ligne reste en anglais : votre application d’IA la comprend.

When I ask you to remember something, save it in Zaaheen. Before answering anything about me, my preferences, my work or my plans, also check my Zaaheen memory, even when your own memory has nothing.

Vous pouvez aussi demander directement, par exemple « consulte ma mémoire Zaaheen pour savoir comment j’aime organiser mes réunions ». Cursor et Antigravity consultent Zaaheen d’eux-mêmes quand vous posez une question sur vous.

Mon application n’est pas dans l’onglet Agents

Agents

Une application n’apparaît dans l’onglet Agents que tant qu’elle est ouverte et connectée. Ouvrez l’application, puis vérifiez ses propres réglages : chaque guide de connexion a une étape de vérification (Claude Desktop, Claude Code, Cursor, ChatGPT). Si Zaaheen n’y figure pas, connectez-le à nouveau.

ChatGPT ne voit pas Zaaheen

ChatGPT

Utilisez le mode Work ou Codex de ChatGPT : son mode Chat ne peut pas se connecter aux applications de votre ordinateur. Vérifiez ensuite le réglage : Command doit commencer exactement par C:\, sans espace ni guillemets avant, et mcp et serve doivent être deux éléments séparés sous Arguments, pas une seule ligne. Quittez complètement ChatGPT et rouvrez-le. Voir Connecter ChatGPT Desktop.

Claude ne m’a pas proposé d’installer Zaaheen

Claude › Extensions

Zaaheen enregistre l’extension dans votre dossier Téléchargements (Downloads). Dans Claude, ouvrez Settings, puis Extensions, puis Advanced settings, puis Install Extension, et choisissez « Zaaheen for Claude.mcpb ».

Windows indique que l’éditeur est inconnu

Programme d’installation

Choisissez More info, puis Run anyway. Si Microsoft Edge indique d’abord que le fichier « isn't commonly downloaded », choisissez les trois points à côté du téléchargement, puis Keep, Show more et Keep anyway. Le programme d’installation n’est pas encore signé ; la signature viendra plus tard.

Mon Mac demande de déplacer Zaaheen dans Applications

Mac

Zaaheen ne fonctionne que depuis le dossier Applications. Si vous l’avez ouvert depuis l’image disque ou depuis Téléchargements, quittez-le, faites glisser Zaaheen dans Applications dans le Finder, puis ouvrez-le depuis cet endroit. Pour trouver Applications, ouvrez le Finder (le visage bleu et blanc à gauche du Dock) et choisissez Applications dans la barre latérale, ou appuyez sur Maj-Commande-A.

Mon Mac demande si Zaaheen peut utiliser le trousseau

Mac

La clé de vos souvenirs est gardée dans le trousseau de votre Mac, macOS demande donc l’autorisation avant que Zaaheen la lise. Choisissez Always Allow. Si Zaaheen indique qu’il n’a pas pu utiliser le stockage sécurisé de cet ordinateur, ouvrez Trousseaux d’accès (Keychain Access), déverrouillez votre trousseau de session, puis réessayez.

Mon application d’IA ne trouve pas un souvenir ajouté dans l’application Zaaheen

Memories

Mettez Zaaheen à jour vers la version 0.3.7 ou plus récente depuis zaaheen.com. Avant la 0.3.7, un souvenir ajouté dans l’application allait dans l’espace default, que les applications d’IA ne pouvaient pas lire. Depuis la 0.3.7, chaque application d’IA lit tous les espaces, y compris les souvenirs ajoutés avant la mise à jour. S’il reste introuvable, vérifiez que le souvenir figure dans l’onglet Memories (ou dans Recently deleted), puis fermez et rouvrez votre application d’IA et redemandez.

Mon application d’IA dit qu’un espace n’existe pas

Boundaries

Les applications d’IA ne peuvent pas créer d’espaces ; vous seul le pouvez. Ouvrez Boundaries, choisissez + New boundary, tapez le nom (lettres, chiffres, - ou _, sans espaces) et choisissez Create boundary. Demandez ensuite à votre application d’IA d’enregistrer à nouveau. Les noms sont exacts, majuscules comprises : si vous avez déjà Health, demandez Health. Voir Comment fonctionnent les espaces.

Mes applications n’utilisent plus Zaaheen

Settings › Account

Si votre essai gratuit ou votre abonnement est terminé, Zaaheen cesse de servir vos applications d’IA jusqu’à ce que vous vous abonniez. Rien n’est supprimé : vos souvenirs restent sur votre ordinateur, et Download my memories continue de fonctionner. Choisissez Subscribe dans l’application, et vos applications retrouvent Zaaheen.

Un autre problème

Settings › Help

Choisissez Save activity record… dans Settings, puis envoyez le fichier par e-mail à customerservice@zaaheen.com en expliquant ce que vous faisiez. Ce journal ne contient aucun de vos souvenirs. Comment nous contacter.
