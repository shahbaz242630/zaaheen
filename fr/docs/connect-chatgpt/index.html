Comment connecter ChatGPT à Zaaheen

Dans ChatGPT Desktop, ouvrez Settings, puis Plugins, puis MCP, et ajoutez un serveur MCP nommé Zaaheen avec la commande affichée dans l’onglet Agents de Zaaheen et les arguments mcp et serve. Utilisez ensuite Zaaheen dans un chat Work ou Codex.

Suivez bien les 3 étapes. Si vous en sautez une, ChatGPT Desktop risque de ne pas utiliser Zaaheen.

Étape 1 : ajoutez-le vous-même

ChatGPT › Settings

Le plus simple pour avoir le bon réglage : dans Zaaheen, ouvrez Agents, choisissez Connect an app, puis ChatGPT Desktop. Le réglage s’affiche avec le chemin propre à cet ordinateur, et un bouton Copy. Utilisez les boutons de copie plutôt que de sélectionner le texte à la main.

Le chemin ci-dessous est un exemple. Il ressemblera à C:\Program Files\Zaaheen\zaaheen.exe, l’emplacement où Zaaheen s’installe habituellement sous Windows. Si vous avez installé Zaaheen ailleurs, par exemple sur un autre disque ou dans un autre dossier, votre chemin est différent et celui-ci ne fonctionnera pas. Copiez votre chemin exact depuis Zaaheen : Agents, Connect an app, ChatGPT Desktop, puis Copy.

1. Dans ChatGPT Desktop, ouvrez Settings, puis Plugins en haut, et choisissez MCP. Ouvrez le menu déroulant en haut à droite et choisissez Add MCP server.

2. Champ Name

Zaaheen

3. Command : collez-la telle quelle, sans espace devant

C:\Program Files\Zaaheen\zaaheen.exe

4. Arguments : tapez mcp dans la première case

mcp

5. Cliquez sur + pour ajouter une deuxième case, et tapez-y serve

serve

6. Cliquez sur Save. Puis quittez complètement ChatGPT (sous Windows, aussi depuis son icône près de l’horloge) et rouvrez-le. Utilisez Zaaheen dans un chat Work ou Codex : le mode Chat de ChatGPT ne peut pas se connecter aux applications de votre ordinateur.

Le chemin ci-dessous est un exemple. Il ressemblera à /Applications/Zaaheen.app/Contents/MacOS/zaaheen, l’emplacement où Zaaheen s’installe habituellement sur un Mac. Si vous avez installé Zaaheen ailleurs, votre chemin est différent et celui-ci ne fonctionnera pas. Copiez votre chemin exact depuis Zaaheen : Agents, Connect an app, ChatGPT Desktop, puis Copy.

Étape 2 : vérifiez que c’est connecté

ChatGPT › Settings

Dans ChatGPT, ouvrez Settings, puis Plugins, puis MCP. Zaaheen y figure et il est activé.

Étape 3 : demandez à ChatGPT Desktop d’utiliser Zaaheen (ne sautez pas cette étape)

ChatGPT › Settings

ChatGPT regarde d’abord dans sa propre mémoire. Dans ChatGPT, ouvrez Settings, puis Personalization, puis Custom instructions, et ajoutez cette ligne :

When I ask you to remember something, save it in Zaaheen. Before answering anything about me, my preferences, my work or my plans, also check my Zaaheen memory, even when your own memory has nothing.
