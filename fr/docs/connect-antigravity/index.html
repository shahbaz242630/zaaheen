Comment connecter Antigravity à Zaaheen

Ouvrez le fichier de réglages d’Antigravity, mcp_config.json, collez-y le réglage de l’onglet Agents de Zaaheen, enregistrez et redémarrez Antigravity. Vérifiez ensuite que Zaaheen apparaît avec un rond vert sous ses outils MCP.

Suivez bien les deux étapes. Si vous en sautez une, Antigravity risque de ne pas utiliser Zaaheen.

Étape 1 : ajoutez-le vous-même

Antigravity › mcp_config.json

Le plus simple pour avoir le bon réglage : dans Zaaheen, ouvrez Agents, choisissez Connect an app, puis Antigravity. Le réglage s’affiche avec le chemin propre à cet ordinateur, et un bouton Copy. Utilisez les boutons de copie plutôt que de sélectionner le texte à la main.

Le chemin ci-dessous est un exemple. Il ressemblera à C:\Program Files\Zaaheen\zaaheen.exe, l’emplacement où Zaaheen s’installe habituellement sous Windows. Si vous avez installé Zaaheen ailleurs, par exemple sur un autre disque ou dans un autre dossier, votre chemin est différent et celui-ci ne fonctionnera pas. Copiez votre chemin exact depuis Zaaheen : Agents, Connect an app, Antigravity, puis Copy.

Ouvrez d’abord son fichier de réglages dans le Bloc-notes (Notepad) : appuyez en même temps sur Windows et R, collez la ligne qui correspond à votre Antigravity, puis appuyez sur Entrée.

Application Antigravity

notepad %USERPROFILE%\.gemini\config\mcp_config.json

IDE Antigravity

notepad %USERPROFILE%\.gemini\antigravity\mcp_config.json

Collez-y ensuite ceci. Si le fichier contient déjà d’autres applications, ajoutez la partie zaaheen à côté. Enregistrez, puis fermez complètement Antigravity et rouvrez-le :

{
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

Le chemin ci-dessous est un exemple. Il ressemblera à /Applications/Zaaheen.app/Contents/MacOS/zaaheen, l’emplacement où Zaaheen s’installe habituellement sur un Mac. Si vous avez installé Zaaheen ailleurs, votre chemin est différent et celui-ci ne fonctionnera pas. Copiez votre chemin exact depuis Zaaheen : Agents, Connect an app, Antigravity, puis Copy.

Ouvrez d’abord son fichier de réglages dans TextEdit : ouvrez Terminal, collez la ligne qui correspond à votre Antigravity, puis appuyez sur Retour.

Application Antigravity

mkdir -p ~/.gemini/config && touch ~/.gemini/config/mcp_config.json && open -e ~/.gemini/config/mcp_config.json

IDE Antigravity

mkdir -p ~/.gemini/antigravity && touch ~/.gemini/antigravity/mcp_config.json && open -e ~/.gemini/antigravity/mcp_config.json

Collez-y ensuite ceci. Si le fichier contient déjà d’autres applications, ajoutez la partie zaaheen à côté. Enregistrez, puis fermez complètement Antigravity et rouvrez-le :

{
  "mcpServers": {
    "zaaheen": {
      "command": "/Applications/Zaaheen.app/Contents/MacOS/zaaheen",
      "args": ["mcp", "serve"]
    }
  }
}

Étape 2 : vérifiez que c’est connecté

Antigravity › mcp_config.json

Dans Antigravity, ouvrez Settings, puis Customization. Sous Token usage, à côté de MCP tools, cliquez sur Show breakdown. Zaaheen figure dans la liste avec un rond vert.
