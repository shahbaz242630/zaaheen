Comment connecter Claude Code à Zaaheen

Dans un terminal, exécutez une seule commande, affichée dans l’onglet Agents de Zaaheen. Zaaheen est ensuite disponible dans tous vos projets Claude Code.

Suivez bien les deux étapes. Si vous en sautez une, Claude Code risque de ne pas utiliser Zaaheen.

Étape 1 : ajoutez-le vous-même

Terminal

Le plus simple pour avoir le bon réglage : dans Zaaheen, ouvrez Agents, choisissez + Connect an AI app, puis Claude Code. Le réglage s’affiche avec le chemin propre à cet ordinateur, et un bouton Copy. Utilisez les boutons de copie plutôt que de sélectionner le texte à la main.

Le chemin ci-dessous est un exemple. Il ressemblera à C:\Program Files\Zaaheen\zaaheen.exe, l’emplacement où Zaaheen s’installe habituellement sous Windows. Si vous avez installé Zaaheen ailleurs, par exemple sur un autre disque ou dans un autre dossier, votre chemin est différent et celui-ci ne fonctionnera pas. Copiez votre chemin exact depuis Zaaheen : Agents, + Connect an AI app, Claude Code, puis Copy.

Dans un terminal, exécutez ceci une fois. Zaaheen est ensuite disponible dans tous vos projets Claude Code :

claude mcp add --transport stdio --scope user zaaheen -- "C:\Program Files\Zaaheen\zaaheen.exe" mcp serve

Le chemin ci-dessous est un exemple. Il ressemblera à /Applications/Zaaheen.app/Contents/MacOS/zaaheen, l’emplacement où Zaaheen s’installe habituellement sur un Mac. Si vous avez installé Zaaheen ailleurs, votre chemin est différent et celui-ci ne fonctionnera pas. Copiez votre chemin exact depuis Zaaheen : Agents, + Connect an AI app, Claude Code, puis Copy.

Dans un terminal, exécutez ceci une fois. Zaaheen est ensuite disponible dans tous vos projets Claude Code :

claude mcp add --transport stdio --scope user zaaheen -- "/Applications/Zaaheen.app/Contents/MacOS/zaaheen" mcp serve

Étape 2 : vérifiez que c’est connecté

Terminal

Dans un terminal, exécutez claude mcp list. Zaaheen apparaît comme connecté.

L’utiliser

Claude Code

Posez à Claude Code des questions sur vous, vos préférences ou votre travail, ou demandez-lui de consulter votre mémoire Zaaheen. Ce qu’il y enregistre, vos autres applications d’IA connectées peuvent aussi l’utiliser.
