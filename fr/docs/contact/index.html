Ce qu’il faut indiquer

Pour vous aider du premier coup
  • Windows ou Mac.
  • L’application d’IA que vous utilisiez.
  • Les mots exacts de tout message d’erreur.
  • Pour un problème dans l’application, son journal d’activité : choisissez Save activity record… dans Settings et joignez le fichier. Il nous indique la version de l’application et ce qui s’est passé, et ne contient aucun de vos souvenirs.

N’envoyez jamais votre mot de passe ni aucun code de connexion. Nous ne vous les demanderons jamais.
