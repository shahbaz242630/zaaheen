Mémoire de ChatGPT ou mémoire de Claude : comment chacun se souvient de vous

Les deux se souviennent bien de vous, et les deux s'activent gratuitement. ChatGPT puise dans davantage de sources, comme les anciennes conversations, des fichiers et des applications connectées. Claude garde sa mémoire sous forme de sujets que vous pouvez lire et modifier, avec une mémoire séparée pour chaque projet. Aucun ne peut lire la mémoire de l'autre : si vous utilisez les deux, chacun ne connaît que la moitié de ce que vous leur avez dit.

Par Zaaheen · Mis à jour le 22 octobre 2026

La réponse courte

Si vous n'utilisez que l'un des deux, sa propre mémoire suffit probablement, et elle ne coûte rien de plus. Les différences tiennent à ce dans quoi chacun puise, à ce que vous pouvez voir et modifier, et à la façon dont ils traitent les informations sensibles. Tout ce qui suit vient des pages d'aide d'OpenAI et d'Anthropic, telles qu'elles se lisaient le 13 octobre 2026 ; les deux précisent que les fonctions varient selon l'offre, donc les vôtres peuvent différer un peu.

Comment ChatGPT se souvient

La mémoire de ChatGPT peut puiser dans plusieurs sources : vos anciennes conversations, les souvenirs enregistrés, vos instructions personnalisées, les fichiers de votre Library et des applications connectées comme Gmail, selon votre offre et votre région (page d'aide d'OpenAI). Les réglages se trouvent dans Settings, Personalization, Memory, où vous pouvez voir un résumé de la mémoire et le corriger. Quand ChatGPT utilise quelque chose dont il se souvient, une liste Sources peut apparaître sous la réponse.

Quelques détails utiles. Supprimer une conversation ne supprime pas un souvenir enregistré qui en est issu ; il faut retirer les deux. Si vous désactivez « Reference chat history », ce qu'il a appris des anciennes conversations est programmé pour suppression sous 30 jours. Et sur les comptes personnels, OpenAI peut utiliser les conversations et les informations mémorisées pour améliorer ses modèles tant que « Improve the model for everyone » est activé, ce que vous pouvez désactiver dans Data controls.

Comment Claude se souvient

La mémoire de Claude est activée par défaut pour Free, Pro et Max sur le web, dans Claude Desktop et dans les applications mobiles. Avec les offres Team et Enterprise, c'est le propriétaire qui décide, et chaque membre l'active pour lui-même (page d'aide d'Anthropic).

Claude enregistre sa mémoire sous forme de sujets pendant que vous discutez, et vous pouvez lire, modifier ou supprimer chacun d'eux dans Settings, Memory. Chaque projet a sa propre mémoire séparée. Chercher dans vos anciennes conversations demande une offre payante. Par défaut, Claude ne garde pas les sujets sensibles comme la santé, la religion ou la politique, sauf si vous choisissez de les inclure, et il n'enregistre jamais certaines choses, comme les numéros de pièce d'identité officielle ou de compte financier.

Si vous utilisez les deux

C'est là que les mémoires intégrées atteignent leurs limites. Chacune vit dans le compte de son entreprise, donc une préférence donnée à ChatGPT le mois dernier ne dit rien à Claude aujourd'hui. Claude peut importer depuis ChatGPT une fois, ce qui aide si vous changez pour de bon, mais tout ce que vous dites ensuite à ChatGPT reste chez ChatGPT.

L'autre solution est une mémoire placée en dehors des deux, à laquelle les deux applications se connectent. Zaaheen, que nous développons, en est une : elle garde vos souvenirs chiffrés sur votre propre ordinateur, et Claude Desktop comme l'application ChatGPT pour votre ordinateur y enregistrent et y lisent.

Nous l'avons testé. Cinq applications d'IA sur un même ordinateur Windows, dont ChatGPT et Claude Desktop, partageaient une mémoire Zaaheen, et nous avons posé huit questions sur la personne, le plus souvent dans une autre application que celle qui avait enregistré la réponse.

La moitié du temps, l'application a consulté la mémoire partagée d'elle-même ; sinon, elle a d'abord répondu avec sa propre mémoire. Ajouter cette ligne (en anglais, telle que l'application la donne) aux instructions de chaque application règle l'essentiel du problème : "When I ask you to remember something, save it in Zaaheen. Before answering anything about me, my preferences, my work or my plans, also check my Zaaheen memory, even when your own memory has nothing."

Deux limites, pour être honnêtes. ChatGPT n'atteint Zaaheen que par l'application ChatGPT pour votre ordinateur, pas dans un navigateur web ni sur votre téléphone. Et Zaaheen fonctionne sur Windows et sur les Mac à puce Apple, sans version pour téléphone. Si vous utilisez une seule application, gardez sa propre mémoire ; si vous utilisez les deux chaque semaine, une mémoire partagée vous évite de vous répéter.

ChatGPT et Claude sont des noms qui appartiennent à leurs propriétaires, OpenAI et Anthropic. Nous n'avons aucun lien avec eux. Si quelque chose ici est faux ou dépassé, écrivez-nous à customerservice@zaaheen.com et nous le corrigerons.

Zaaheen est une mémoire privée unique pour Claude, ChatGPT, Cursor et vos autres applications d’IA, conservée chiffrée sur votre propre ordinateur. 30 jours gratuits, sans carte.
