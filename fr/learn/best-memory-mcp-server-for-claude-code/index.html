Quel serveur MCP de mémoire utiliser avec Claude Code ?

Il n'y a pas de meilleur choix unique ; tout dépend de l'usage que vous voulez faire de la mémoire. Pour une mémoire gratuite et simple, rien que pour Claude Code, le serveur de référence d'Anthropic ou mcp-memory-service feront l'affaire. Pour des notes que vous pouvez lire vous-même, Basic Memory. Pour une mémoire chiffrée unique que Claude Code partage avec Cursor, ChatGPT et Claude Desktop, sans Python ni fichiers de configuration, c'est pour cela que nous avons créé Zaaheen.

Par Zaaheen · Mis à jour le 22 octobre 2026

Ce qu’un serveur de mémoire apporte à Claude Code

Claude Code se souvient déjà au sein d'un projet : CLAUDE.md, que vous écrivez, et l'auto memory, qu'il écrit, tous deux conservés sur votre ordinateur pour ce dépôt-là (documentation d'Anthropic). Un serveur de mémoire ajoute une mémoire dans laquelle Claude Code peut chercher et enregistrer dans tous vos projets, et, selon le serveur, que d'autres applications d'IA peuvent utiliser aussi.

Les options

Le serveur de mémoire de référence d'Anthropic

Il se décrit lui-même comme « A basic implementation of persistent memory using a local knowledge graph » (une implémentation de base d'une mémoire persistante à l'aide d'un graphe de connaissances local). Il est gratuit et sous licence MIT. Vous ajoutez une commande npx aux réglages de votre application, ou vous le lancez avec Docker, et il stocke tout dans un fichier appelé memory.jsonl (sa page GitHub). Sa page ne mentionne pas de chiffrement.

mcp-memory-service

Un serveur de mémoire gratuit et open source que vous installez avec pip. Il peut stocker les souvenirs localement dans SQLite, ou dans Cloudflare et d'autres backends, et cite Claude Code, Cursor, Codex et Claude Desktop parmi les applications avec lesquelles il fonctionne (sa page GitHub). Il a beaucoup d'options, ce qui convient aux personnes qui aiment configurer leurs outils.

Basic Memory

Écrit les souvenirs sous forme de simples notes Markdown que vous pouvez ouvrir et modifier. La version locale est gratuite et demande Python 3.12 ou plus, installé avec uv ou, sur Mac, Homebrew (son guide de démarrage rapide). Une version Cloud hébergée démarre à 15 USD par mois (site de Basic Memory).

Mem0

Une mémoire hébergée : son serveur MCP tourne chez Mem0 et vos souvenirs vivent dans votre compte Mem0, avec une offre Hobby gratuite (documentation de Mem0). Un bon choix si vous voulez la mémoire en ligne plutôt que sur un seul ordinateur.

Zaaheen

La nôtre. Une application pour Windows et Mac qui garde une mémoire unique, chiffrée sur votre ordinateur. Pour Claude Code, vous copiez une commande depuis l'onglet Agents de Zaaheen et la lancez une fois ; ensuite, elle est là dans tous vos projets (pas à pas). La même mémoire est partagée avec Cursor, Claude Desktop, l'application ChatGPT, Codex et d'autres applications.

Ce que coûte une année

Les options gratuites sont gratuites. Ce que vous payez avec Zaaheen, c'est aucune mise en place au-delà d'une commande, le chiffrement sur votre ordinateur, et une mémoire unique que vos autres applications d'IA partagent.

Comment choisir

Si vous n'utilisez que Claude Code et aimez configurer les choses, commencez par l'un des serveurs gratuits. Si vous voulez lire et modifier votre mémoire sous forme de notes, utilisez Basic Memory. Si vous voulez la mémoire en ligne, regardez Mem0. Si vous utilisez aussi Cursor, Claude Desktop ou ChatGPT et voulez qu'ils partagent tous ce que Claude Code apprend, chiffré sur votre propre ordinateur, essayez Zaaheen gratuitement pendant 30 jours.

Les limites de Zaaheen : uniquement Windows et les Mac à puce Apple, pas de Linux ; un seul ordinateur, sans synchronisation pour l'instant ; pas open source ; pas d'offre gratuite après l'essai.

Claude Code, Mem0 et Basic Memory sont des noms qui appartiennent à leurs propriétaires, et les serveurs open source appartiennent à leurs auteurs. Nous n'avons aucun lien avec eux.
