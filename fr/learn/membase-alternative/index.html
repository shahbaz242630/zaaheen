Une alternative à Membase qui garde votre mémoire chiffrée sur votre ordinateur

Membase est une mémoire hébergée pour les applications et agents d'IA, avec une extension de navigateur, un serveur MCP et des outils pour les développeurs. Son propre site indique que le service hébergé n'est pas chiffré de bout en bout. Si vous voulez une mémoire unique pour ChatGPT, Claude et Cursor qui reste chiffrée sur votre propre ordinateur et ne demande aucune clé d'API, Zaaheen est fait pour ça.

Par Zaaheen · Mis à jour le 12 novembre 2026

Ce qu’est Membase

Cette page parle de Membase sur membase.com, conçu par une entreprise appelée Unibase. Un autre produit, sur membase.so, porte aussi ce nom ; les deux n'ont aucun lien (site de Membase).

Membase construit une mémoire à long terme unique à partir de vos conversations et de vos fichiers. Son extension de navigateur fonctionne avec ChatGPT, Claude, Gemini, Grok, DeepSeek et Kimi dans Chrome, et Claude Code, Cursor et Codex se connectent via son serveur MCP. Les développeurs peuvent aussi l'utiliser depuis leur code. Une application de bureau est annoncée comme bientôt disponible (sa page d'accueil).

Votre mémoire est conservée sur le service de Membase, qui selon sa politique de confidentialité fonctionne sur Amazon Web Services à Singapour, et les parties utiles de ce que vous enregistrez sont envoyées à son fournisseur d'IA, actuellement OpenAI (sa politique de confidentialité). Il existe aussi un mode local pour ceux qui utilisent Python, qui garde la mémoire dans un dossier sur votre ordinateur mais demande votre propre clé d'API OpenAI (sa page GitHub).

Ce qui distingue Zaaheen

  • Chiffrée sur votre ordinateur, par défaut. Zaaheen garde vos souvenirs chiffrés sur votre propre ordinateur, et nos serveurs ne les reçoivent jamais. Le service hébergé de Membase, son choix par défaut, n'est pas chiffré de bout en bout, selon ses propres mots.
  • Pas de clé d'API, pas de service d'IA extérieur. Zaaheen fait tourner ses propres modèles d'IA sur votre ordinateur, donc vos souvenirs ne sont jamais envoyés à une entreprise d'IA pour être triés ou recherchés. Le mode local de Membase demande quand même une clé OpenAI.
  • Une application terminée pour Windows et Mac. Zaaheen s'installe comme n'importe quelle application, et vous connectez chaque application d'IA depuis son onglet Agents. L'application de bureau de Membase n'est pas encore sortie.
  • Un code que vous pouvez lire. Tout le code de Zaaheen est public et lisible, donc chacun peut vérifier comment vos souvenirs sont traités. Membase publie ses outils, mais son moteur de mémoire est livré sous forme de paquet fermé et compilé.

Ce qui compte le plus dans une mémoire, c'est que la bonne réponse revienne, et que l'application le reconnaisse quand la mémoire n'en contient pas. Nous avons posé à Cursor cinq questions sur des informations qu'une autre application avait enregistrées dans une mémoire Zaaheen partagée.

Quand Membase est le meilleur choix

Si vous utilisez surtout l'IA dans un navigateur web, l'extension de Membase y rejoint ChatGPT, Gemini, Grok et d'autres, ce que Zaaheen ne fait pas. Elle peut aussi construire une mémoire à partir des fichiers et des pages que vous enregistrez, et les développeurs disposent d'une API et d'outils pour construire avec. Et si cela ne vous gêne pas que votre mémoire soit en ligne, elle vous suit sur n'importe quel ordinateur.

Les limites de Zaaheen

  • Elle fonctionne uniquement sur Windows et sur les Mac à puce Apple, sans version Linux ni pour téléphone.
  • ChatGPT se connecte via l'application ChatGPT pour votre ordinateur, pas dans un navigateur web.
  • Votre mémoire vit sur un seul ordinateur ; il n'y a pas encore de synchronisation entre ordinateurs.
  • Elle n'est pas open source, et après l'essai gratuit de 30 jours, il n'y a pas d'offre gratuite.
