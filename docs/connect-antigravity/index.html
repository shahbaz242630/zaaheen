How to connect Antigravity to Zaaheen

Open Antigravity's settings file, mcp_config.json, paste Zaaheen's setting from the Agents tab in Zaaheen, save, and restart Antigravity. Then check Zaaheen shows with a green circle under its MCP tools.

    Please follow both steps. If you skip one, Antigravity may not use Zaaheen.

    Step 1: Add it yourself

    Antigravity › mcp_config.json

    The easiest way to get the setting right: in Zaaheen, open Agents, choose + Connect an AI app, then Antigravity. It shows the setting with this computer's own path, with a Copy button. Use the Copy buttons rather than selecting text by hand.

    The path below is an example. It will look like C:\Program Files\Zaaheen\zaaheen.exe, which is where Zaaheen usually installs on Windows. If you installed Zaaheen somewhere else, such as another drive or folder, your path is different, and this one will not work. Copy your exact path from Zaaheen: Agents, + Connect an AI app, Antigravity, then Copy.

    First open its settings file in Notepad: press Windows and R together, paste the line for your Antigravity, and press Enter.

    Antigravity app

    notepad %USERPROFILE%\.gemini\config\mcp_config.json

    Antigravity IDE

    notepad %USERPROFILE%\.gemini\antigravity\mcp_config.json

    Then paste this in. If the file already lists other apps, add the zaaheen part next to them. Save it, then close Antigravity fully and open it again:

    {
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

    The path below is an example. It will look like /Applications/Zaaheen.app/Contents/MacOS/zaaheen, which is where Zaaheen usually installs on a Mac. If you installed Zaaheen somewhere else, your path is different, and this one will not work. Copy your exact path from Zaaheen: Agents, + Connect an AI app, Antigravity, then Copy.

    First open its settings file in TextEdit: open Terminal, paste the line for your Antigravity, and press Return.

    Antigravity app

    mkdir -p ~/.gemini/config && touch ~/.gemini/config/mcp_config.json && open -e ~/.gemini/config/mcp_config.json

    Antigravity IDE

    mkdir -p ~/.gemini/antigravity && touch ~/.gemini/antigravity/mcp_config.json && open -e ~/.gemini/antigravity/mcp_config.json

    Then paste this in. If the file already lists other apps, add the zaaheen part next to them. Save it, then close Antigravity fully and open it again:

    {
  "mcpServers": {
    "zaaheen": {
      "command": "/Applications/Zaaheen.app/Contents/MacOS/zaaheen",
      "args": ["mcp", "serve"]
    }
  }
}

    Step 2: Check it's connected

    Antigravity › mcp_config.json

    In Antigravity, open Settings, then Customization. Under Token usage, next to MCP tools, click Show breakdown. Zaaheen is listed with a green circle.
