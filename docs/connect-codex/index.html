How to connect Codex to Zaaheen

Add Zaaheen's setting to Codex's config.toml (the Agents tab in Zaaheen shows it for your computer), restart Codex, and check /mcp lists zaaheen as connected. Already connected ChatGPT Desktop? Codex shares its settings, so just check it's connected.

    Already connected ChatGPT Desktop? Codex uses the same settings, so you don't need to add Zaaheen again. Just do Step 2 to check it's connected, then ask Codex to save or recall using Zaaheen.

    Please follow all 3 steps. If you skip one, Codex may not use Zaaheen.

    Step 1: Add it yourself

    Codex › config.toml

    The easiest way to get the setting right: in Zaaheen, open Agents, choose + Connect an AI app, then Codex. It shows the setting with this computer's own path, with a Copy button. Use the Copy buttons rather than selecting text by hand.

    The path below is an example. It will look like C:\Program Files\Zaaheen\zaaheen.exe, which is where Zaaheen usually installs on Windows. If you installed Zaaheen somewhere else, such as another drive or folder, your path is different, and this one will not work. Copy your exact path from Zaaheen: Agents, + Connect an AI app, Codex, then Copy.

    Use an up-to-date Codex. Add this to Codex's settings file, config.toml, in the .codex folder in your home folder. If the file already has a [mcp_servers.zaaheen] section, don't add a second one. Save it, then restart Codex:

    [mcp_servers.zaaheen]
command = "C:\\Program Files\\Zaaheen\\zaaheen.exe"
args = ["mcp", "serve"]

    The path below is an example. It will look like /Applications/Zaaheen.app/Contents/MacOS/zaaheen, which is where Zaaheen usually installs on a Mac. If you installed Zaaheen somewhere else, your path is different, and this one will not work. Copy your exact path from Zaaheen: Agents, + Connect an AI app, Codex, then Copy.

    Use an up-to-date Codex. Add this to Codex's settings file, config.toml, in the .codex folder in your home folder. If the file already has a [mcp_servers.zaaheen] section, don't add a second one. Save it, then restart Codex:

    [mcp_servers.zaaheen]
command = "/Applications/Zaaheen.app/Contents/MacOS/zaaheen"
args = ["mcp", "serve"]

    Step 2: Check it's connected

    Codex › config.toml

    In Codex, type /mcp and press Enter. zaaheen is listed as connected, with 5 tools. If it shows no tools or says it timed out, update Codex (npm install -g @openai/codex@latest) and try again.

    Step 3: Tell Codex to use Zaaheen (don't skip this)

    Codex › config.toml

    Codex looks in its own knowledge first. Add this line to the file AGENTS.md in the .codex folder in your home folder (make the file if it isn't there):

    When I ask you to remember something, save it in Zaaheen. Before answering anything about me, my preferences, my work or my plans, also check my Zaaheen memory, even when your own memory has nothing.
