Fixing common problems with Zaaheen

Most problems come from an AI app looking only in its own memory, or not being connected yet. Each fix below starts with the answer. If yours isn't here, contact us with an activity record from Settings.

    Error messages and their fixes

    Any app

    Find the words you see, then do what it says next to them.

    Invalid result for tools/call: missing required resultType Claude Code, when it calls Zaaheen
    Update Zaaheen to the latest version from zaaheen.com: version 0.3.1 and later answer the newest apps correctly.
    The filename, directory name, or volume label syntax is incorrect. (os error 123) ChatGPT Desktop or Codex, in the app's log; ChatGPT itself only says Zaaheen isn't accessible
    The Command has a space or quote marks before C:. Edit the MCP server so the Command starts exactly with C:\ (copy it with the Copy button in Zaaheen's Agents tab), save, and restart ChatGPT.
    Zaaheen isn't accessible in this chat ChatGPT Desktop
    Use a Work or Codex chat (ChatGPT's Chat mode can't connect to apps on your computer), check the Command has no space before it, then quit ChatGPT completely and open it again.
    request timed out (zaaheen: Tools: (none)) Codex in the terminal, after /mcp
    Update Codex (npm install -g @openai/codex@latest), then run codex again and type /mcp: zaaheen shows as connected with 5 tools.
    The AI app saves to its own memory, or answers "I don't know", instead of using Zaaheen Claude Desktop, ChatGPT Desktop, Codex
    Add Zaaheen's line to the app's instructions (Claude: Settings, Account, Instructions for Claude; ChatGPT: Custom instructions; Codex: AGENTS.md in the .codex folder). The line is on this page and in each connect guide.
    Double-clicking "Zaaheen for Claude.mcpb" asks which app to open it with Windows, with Claude from the Microsoft Store
    Cancel that box. In Claude, open Settings, then Extensions, then Advanced settings, then Install Extension, and choose "Zaaheen for Claude.mcpb".
    isn't commonly downloaded. Make sure you trust [the Zaaheen installer] before you open it. Microsoft Edge, when downloading
    Choose the three dots next to the download, then Keep, then Show more, then Keep anyway. The installer is new and not code-signed yet, so Edge has not seen it often.
    Windows protected your PC. Microsoft Defender SmartScreen prevented an unrecognized app from starting. Windows, when opening the installer
    Choose More info, then Run anyway.
    Your memories were NOT deleted, and they are still readable. Mac, after Delete everything or Delete my account in Zaaheen 0.3.0
    Update Zaaheen to the latest version from zaaheen.com (0.3.1 or later), then try again. Nothing was deleted, and your account and subscription were not changed.
    Still working. This is taking longer than usual. Please keep Zaaheen open. Mac, during Delete everything or Delete my account
    macOS may be asking about Zaaheen and your keychain in a box behind the Zaaheen window: look for it and choose Allow. The delete then finishes. Nothing is deleted until your key is gone, so if you close Zaaheen instead, your memories are still there and you can try again.
    This site can't be reached (or another browser error) right after signing in Your browser, after signing in from the Zaaheen app
    Go back to the Zaaheen app: it shows whether you are signed in. The page after sign-in only confirms it, so it does not matter if that page failed to load.

    My AI app answers without using Zaaheen

    Claude, ChatGPT, Codex

    Claude, ChatGPT and Codex look in their own memory first and may stop there, or save there. Add this line to Claude's Instructions for Claude (Settings, then Account), to ChatGPT's Custom instructions, or to the file AGENTS.md in Codex's .codex folder, and they save to and check Zaaheen as well:

    When I ask you to remember something, save it in Zaaheen. Before answering anything about me, my preferences, my work or my plans, also check my Zaaheen memory, even when your own memory has nothing.

    You can also ask directly, for example "check my Zaaheen memory for how I like meetings booked". Cursor and Antigravity check Zaaheen by themselves when you ask about yourself.

    My app isn't in the Agents tab

    Agents

    An app shows in the Agents tab only while it is open and connected. Open the app, then check its own settings: each connection guide has a "Check it worked" step (Claude Desktop, Claude Code, Cursor, ChatGPT). If Zaaheen isn't listed there, connect it again.

    ChatGPT can't see Zaaheen

    ChatGPT

    Use ChatGPT's Work or Codex mode: its Chat mode can't connect to apps on your computer. Then check the setting: the Command must start exactly with C:\, with no space or quote marks before it, and mcp and serve must be two separate items under Arguments, not one line. Quit ChatGPT completely and open it again. See Connect ChatGPT Desktop.

    Claude didn't ask me to install Zaaheen

    Claude › Extensions

    Zaaheen saves the extension to your Downloads folder. In Claude, open Settings, then Extensions, then Advanced settings, then Install Extension, and choose "Zaaheen for Claude.mcpb".

    Windows says the publisher is unknown

    Installer

    Choose More info, then Run anyway. If Microsoft Edge says the file "isn't commonly downloaded" first, choose the three dots next to the download, then Keep, Show more and Keep anyway. Zaaheen is in beta and its installer is not code-signed yet; signing comes later.

    My Mac says to move Zaaheen to Applications

    Mac

    Zaaheen runs only from the Applications folder. If you opened it from the disk image or from Downloads, quit it, drag Zaaheen into Applications in Finder, then open it from there.

    My Mac asks whether Zaaheen can use the keychain

    Mac

    The key to your memories is kept in your Mac's keychain, so macOS asks before Zaaheen reads it. Choose Always Allow. If Zaaheen says it couldn't use this computer's secure storage, open Keychain Access, unlock your login keychain, then try again.

    My apps stopped using Zaaheen

    Settings › Account

    If your free trial or subscription has ended, Zaaheen stops serving your AI apps until you subscribe. Nothing is deleted: your memories stay on your computer, and Download my memories keeps working. Choose Subscribe in the app, and your apps pick Zaaheen up again.

    Something else went wrong

    Settings › Help

    Choose Save activity record… in Settings, then email the file to customerservice@zaaheen.com with what you were doing. The record contains none of your memories. How to contact us.
