How to connect Cursor to Zaaheen

In Zaaheen, open the Agents tab, choose + Connect an AI app, then Cursor Desktop and Connect it for me. Cursor opens and asks you to install Zaaheen, which can take up to a minute: click Install. The Cursor IDE then uses the same connection.

    Using the Cursor IDE? Connect Zaaheen here, through Cursor Desktop: the IDE has no MCP settings of its own, and it uses the ones you set in Cursor Desktop, so connecting once is enough for both.

    Please follow both steps. If you skip one, Cursor Desktop may not use Zaaheen.

    Step 1A: The quick way

    Zaaheen › Agents

    Zaaheen opens Cursor, and Cursor asks you to install Zaaheen. It can take up to a minute for Cursor to open and show its Install box, so please wait for it, then click Install.

    1. In Zaaheen, open the Agents tab and choose + Connect an AI app.
    2. Choose Cursor Desktop, then Connect it for me.
    3. Waiting for Cursor to open and show its Install box. This can take up to a minute.
    4. Cursor should now be showing its Install box. Click Install, and it's connected. If nothing has appeared, switch to the Cursor window: the box may be behind this one.

    Step 1B: Or add it yourself

    Cursor › Customize

    The easiest way to get the setting right: in Zaaheen, open Agents, choose + Connect an AI app, then Cursor Desktop. It shows the setting with this computer's own path, with a Copy button. Use the Copy buttons rather than selecting text by hand.

    The path below is an example. It will look like C:\Program Files\Zaaheen\zaaheen.exe, which is where Zaaheen usually installs on Windows. If you installed Zaaheen somewhere else, such as another drive or folder, your path is different, and this one will not work. Copy your exact path from Zaaheen: Agents, + Connect an AI app, Cursor Desktop, then Copy.

    In Cursor Desktop, choose Customize in the left bar, then MCPs. Scroll to the bottom, choose + New MCP server, and paste this in. Save it:

    {
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

    The path below is an example. It will look like /Applications/Zaaheen.app/Contents/MacOS/zaaheen, which is where Zaaheen usually installs on a Mac. If you installed Zaaheen somewhere else, your path is different, and this one will not work. Copy your exact path from Zaaheen: Agents, + Connect an AI app, Cursor Desktop, then Copy.

    In Cursor Desktop, choose Customize in the left bar, then MCPs. Scroll to the bottom, choose + New MCP server, and paste this in. Save it:

    {
  "mcpServers": {
    "zaaheen": {
      "command": "/Applications/Zaaheen.app/Contents/MacOS/zaaheen",
      "args": ["mcp", "serve"]
    }
  }
}

    Step 2: Check it's connected

    Cursor › Customize

    In Cursor Desktop, choose Customize in the left bar, then MCPs. zaaheen is listed there and connected.
