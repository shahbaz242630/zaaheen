How to connect Cursor to Zaaheen

In Zaaheen, open the Agents tab, choose + Connect an AI app, then Cursor and Connect it for me. Cursor asks you to install Zaaheen: click Install, and it's connected.

Connect it

Agents › Connect

Zaaheen opens Cursor's own install link, and Cursor asks you. Zaaheen never changes Cursor's settings itself.

  1. In Zaaheen, open the Agents tab and choose + Connect an AI app.
  2. Choose Cursor, then Connect it for me.
  3. Cursor asks you to install Zaaheen. Click Install, and it's connected.

Add the setting yourself

Cursor › mcp.json

If Zaaheen says it couldn't find or open Cursor, add the setting yourself. Add this to Cursor's settings file, mcp.json, in the .cursor folder in your home folder. Save it, then restart Cursor:

{
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

That is where Zaaheen usually installs. The Agents tab shows the setting for your computer exactly, ready to copy.

Check it worked

Cursor › Settings

In Cursor, open Settings, then MCP (Tools & MCP in newer versions). Zaaheen has a green dot.

Using it

Cursor

Cursor checks Zaaheen by itself when you ask about yourself, your preferences or your work. What it saves there, your other connected AI apps can use too.
