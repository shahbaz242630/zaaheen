How to connect Claude Desktop to Zaaheen

In Zaaheen, open the Agents tab, choose + Connect an AI app, then Claude Desktop and Save the extension, and install it in Claude. Then add one line to Claude's instructions so it uses Zaaheen. It works in Claude's Chat and Cowork.

    Please follow all 3 steps. If you skip one, Claude Desktop may not use Zaaheen.

    Step 1A: The quick way

    Zaaheen › Agents

    Zaaheen saves a small Claude extension, and Claude asks you to install it.

    1. In Zaaheen, open the Agents tab and choose + Connect an AI app.
    2. Choose Claude Desktop, then Save the extension.
    3. Zaaheen saved the extension to your Downloads folder. In Claude, open Settings, then Extensions, then Advanced settings, then Install Extension, and choose "Zaaheen for Claude.mcpb".

    If Claude opens and asks you to install Zaaheen instead, click Install, and it's connected.

    Step 1B: Or add it yourself

    Claude › Settings

    The easiest way to get the setting right: in Zaaheen, open Agents, choose + Connect an AI app, then Claude Desktop. It shows the setting with this computer's own path, with a Copy button. Use the Copy buttons rather than selecting text by hand.

    The path below is an example. It will look like C:\Program Files\Zaaheen\zaaheen.exe, which is where Zaaheen usually installs on Windows. If you installed Zaaheen somewhere else, such as another drive or folder, your path is different, and this one will not work. Copy your exact path from Zaaheen: Agents, + Connect an AI app, Claude Desktop, then Copy.

    In Claude, open Settings, then Developer, then Edit Config. Add this to the file it shows you, save it, then quit Claude and open it again:

    {
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

    The path below is an example. It will look like /Applications/Zaaheen.app/Contents/MacOS/zaaheen, which is where Zaaheen usually installs on a Mac. If you installed Zaaheen somewhere else, your path is different, and this one will not work. Copy your exact path from Zaaheen: Agents, + Connect an AI app, Claude Desktop, then Copy.

    In Claude, open Settings, then Developer, then Edit Config. Add this to the file it shows you, save it, then quit Claude and open it again:

    {
  "mcpServers": {
    "zaaheen": {
      "command": "/Applications/Zaaheen.app/Contents/MacOS/zaaheen",
      "args": ["mcp", "serve"]
    }
  }
}

    Step 2: Check it's connected

    Claude › Settings

    In Claude, open Settings, then Extensions. Zaaheen is listed there and switched on. If you added it yourself (Step 1B), it is listed under Settings, then Developer, instead.

    Step 3: Tell Claude Desktop to use Zaaheen (don't skip this)

    Claude › Settings

    Claude looks in its own memory first. In Claude, open Settings, then Account, and add this line under Instructions for Claude:

    When I ask you to remember something, save it in Zaaheen. Before answering anything about me, my preferences, my work or my plans, also check my Zaaheen memory, even when your own memory has nothing.
