How to connect ChatGPT to Zaaheen

In ChatGPT Desktop, open Settings, then Plugins, then MCP, and add an MCP server named Zaaheen with the command from Zaaheen's Agents tab and the arguments mcp and serve. Then use Zaaheen in a Work or Codex chat.

    Please follow all 3 steps. If you skip one, ChatGPT Desktop may not use Zaaheen.

    Step 1: Add it yourself

    ChatGPT › Settings

    The easiest way to get the setting right: in Zaaheen, open Agents, choose + Connect an AI app, then ChatGPT Desktop. It shows the setting with this computer's own path, with a Copy button. Use the Copy buttons rather than selecting text by hand.

    The path below is an example. It will look like C:\Program Files\Zaaheen\zaaheen.exe, which is where Zaaheen usually installs on Windows. If you installed Zaaheen somewhere else, such as another drive or folder, your path is different, and this one will not work. Copy your exact path from Zaaheen: Agents, + Connect an AI app, ChatGPT Desktop, then Copy.

    1. In ChatGPT Desktop, open Settings, then Plugins at the top, and choose MCP. Open the drop-down in the top right corner and choose Add MCP server.

    2. Name

    Zaaheen

    3. Command: paste it exactly, with no space before it

    C:\Program Files\Zaaheen\zaaheen.exe

    4. Arguments: type mcp in the first box

    mcp

    5. Click + to add a second box, and type serve in it

    serve

    6. Click Save. Then quit ChatGPT completely (on Windows, also from its icon by the clock) and open it again. Use Zaaheen in a Work or Codex chat: ChatGPT's Chat mode can't connect to apps on your computer.

    Step 2: Check it's connected

    ChatGPT › Settings

    In ChatGPT, open Settings, then Plugins, then MCP. Zaaheen is listed there and switched on.

    Step 3: Tell ChatGPT Desktop to use Zaaheen (don't skip this)

    ChatGPT › Settings

    ChatGPT looks in its own memory first. In ChatGPT, open Settings, then Personalization, then Custom instructions, and add this line:

    When I ask you to remember something, save it in Zaaheen. Before answering anything about me, my preferences, my work or my plans, also check my Zaaheen memory, even when your own memory has nothing.
