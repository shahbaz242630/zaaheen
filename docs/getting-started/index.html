How to install and set up Zaaheen

Download the Zaaheen installer for Windows, open it, then choose Begin set up. Setting up takes about three minutes: you create your account (your 30-day free trial starts straight away, no card needed), choose where your memories live, and connect your first AI app.

Before you start

Windows

Zaaheen for Windows is coming soon. These steps are how it works once you can download it.

Zaaheen 0.2.2 is a beta for 64-bit Windows and has been tested on Windows 11. It is not available for macOS or Linux yet.

Install

Windows installer

Open the installer you downloaded. Two things happen while it installs:

  • Windows says the publisher is unknown. Zaaheen is in beta, and the installer is not code-signed yet; signing comes before the full launch. Choose More info, then Run anyway.
  • Windows asks for administrator permission. Zaaheen installs for everyone on the computer, so Windows asks once. It does not need administrator rights to run afterwards.

Set up

Begin set up

Open Zaaheen and choose Begin set up. It walks you through five steps:

  1. Your account. Choose Create an account or Sign in. This opens your web browser. Your 30-day free trial starts when you create your account, and no card is needed. Signing in never shares your memories with us.
  2. Where to keep your memories. The usual place suits most people. You can change it later from Settings with Move my memories….
  3. Your first AI app. Pick the app you use and follow the steps, or choose I'll connect one later.
  4. Your first memory. Tell Zaaheen something your AI apps should know about you, then choose Keep this memory, or Skip for now.
  5. Tidying up. Choose whether Zaaheen keeps your memory tidy on its own, then Finish setup.

The first time, Zaaheen also downloads what it needs to search your memories. It does this in the background, and you can use Zaaheen while it finishes.

What to do next

Agents

Connect the AI apps you use, each once, from the Agents tab:

  • Connect Claude
  • Connect Cursor
  • Connect ChatGPT
  • Connect other AI apps

If something doesn't work as described, see Fixing common problems.
