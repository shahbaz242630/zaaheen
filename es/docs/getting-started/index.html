Cómo instalar y configurar Zaaheen

Descarga Zaaheen para Windows o Mac e instálalo, y luego elige Begin set up. La configuración tarda unos tres minutos: inicias sesión desde la app, lo que empieza tu prueba gratis de 30 días (sin tarjeta), eliges dónde se guardan tus recuerdos y conectas tu primera app de IA. La app está en inglés.

Antes de empezar

Windows o Mac

Zaaheen 0.3.8 es para Windows de 64 bits, probado en Windows 11, y para Macs con chip de Apple, M1 o posterior, probado en macOS 26. Todavía no está disponible para Linux ni para teléfonos.

Descargar para Windows Descargar para Mac

Instalar

Windows o Mac

En Windows, abre el instalador que descargaste. Puede que veas hasta tres preguntas por el camino, y todas son normales:

  • Microsoft Edge dice que el archivo "isn't commonly downloaded". El instalador es nuevo, así que Edge no lo ha visto muchas veces. Elige los tres puntos junto a la descarga, y luego Keep, Show more y Keep anyway. Chrome no lo pregunta.
  • Windows dice que el editor es desconocido. El instalador todavía no tiene firma de código; la firma llegará más adelante. Elige More info y luego Run anyway.
  • Windows pide permiso de administrador. Zaaheen se instala para todas las personas que usan la computadora, así que Windows lo pregunta una vez. Después no necesita permisos de administrador para funcionar.

En un Mac, abre la imagen de disco que descargaste, arrastra Zaaheen a la carpeta Applications y luego abre Zaaheen desde Applications. Zaaheen solo funciona desde allí.

  • Tu Mac pregunta si quieres abrir una app descargada de internet. Muestra el nombre del desarrollador. La app para Mac está firmada y revisada por Apple. Elige Open.
  • Tu Mac puede preguntar si Zaaheen puede usar tu llavero (keychain). Ahí es donde se guarda la clave de tus recuerdos. Elige Always Allow.

Para comprobar tu descarga, compara su huella (SHA-256) con la que aparece abajo. Si no coinciden, borra el archivo y vuelve a descargarlo desde este sitio.

  • Windows (Zaaheen_0.3.8_x64.msi): 50147fc643b9e8d4e743c60acbd5c21a34e6672d211534d7add288f28c20d0e4. En PowerShell, ejecuta Get-FileHash "$HOME\Downloads\Zaaheen_0.3.8_x64.msi".
  • Mac (Zaaheen_0.3.8_aarch64.dmg): ae694d3d02ef0d38b591c70db3b4710673f3549c5c9a0d6956d145ce39ed12ab. En Terminal, ejecuta shasum -a 256 ~/Downloads/Zaaheen_0.3.8_aarch64.dmg.

Configurar

Begin set up

Abre Zaaheen y elige Begin set up. Te guía en cinco pasos:

  1. Tu cuenta. Elige Create an account o Sign in. Se abre tu navegador web. Tu prueba gratis de 30 días empieza la primera vez que inicias sesión desde la app de Zaaheen, y no necesitas tarjeta. Iniciar sesión nunca nos comparte tus recuerdos.
  2. Dónde guardar tus recuerdos. El lugar habitual le va bien a la mayoría. Puedes cambiarlo más tarde desde Settings con Move my memories….
  3. Tu primera app de IA. Elige la app que usas y sigue los pasos, o elige I'll connect one later.
  4. Tu primer recuerdo. Cuéntale a Zaaheen algo que tus apps de IA deberían saber sobre ti, y luego elige Keep this memory, o Skip for now.
  5. Limpieza. Zaaheen ordena tu memoria por su cuenta cada noche, salvo que elijas Not now; luego elige Finish setup.

La primera vez, Zaaheen también descarga lo que necesita para buscar en tus recuerdos. Lo hace en segundo plano, y puedes usar Zaaheen mientras termina.

Qué hacer después

Agents

Conecta las apps de IA que usas, cada una una sola vez, desde la pestaña Agents:

  • Conectar Claude Desktop
  • Conectar Claude Code
  • Conectar Cursor
  • Conectar ChatGPT
  • Conectar Codex
  • Conectar Antigravity
  • Conectar otras apps de IA

Si algo no funciona como se describe, consulta Solución de problemas.
