Cómo conectar Cursor a Zaaheen

En Zaaheen, abre la pestaña Agents, elige Connect an app, luego Cursor Desktop y Connect it for me. Cursor se abre y te pide que instales Zaaheen, lo que puede tardar hasta un minuto: haz clic en Install. Después, el Cursor IDE usa la misma conexión.

¿Usas el Cursor IDE? Conecta Zaaheen aquí, a través de Cursor Desktop: el IDE no tiene configuración MCP propia y usa la que defines en Cursor Desktop, así que conectarlo una vez basta para los dos.

Sigue los dos pasos. Si te saltas uno, puede que Cursor Desktop no use Zaaheen.

Paso 1A: La forma rápida

Zaaheen › Agents

Zaaheen abre Cursor, y Cursor te pide que instales Zaaheen. Cursor puede tardar hasta un minuto en abrirse y mostrar su cuadro Install, así que espéralo y luego haz clic en Install.

  1. En Zaaheen, abre la pestaña Agents y elige Connect an app.
  2. Elige Cursor Desktop y luego Connect it for me.
  3. Esperando a que Cursor se abra y muestre su cuadro Install. Puede tardar hasta un minuto.
  4. Cursor debería estar mostrando ahora su cuadro Install. Haz clic en Install, y queda conectado. Si no ha aparecido nada, cambia a la ventana de Cursor: puede que el cuadro esté detrás de esta.

Paso 1B: O añádelo tú

Cursor › Customize

La forma más fácil de acertar con la configuración: en Zaaheen, abre Agents, elige Connect an app y luego Cursor Desktop. Te muestra la configuración con la ruta propia de esta computadora, con un botón Copy. Usa los botones Copy en lugar de seleccionar el texto a mano.

La ruta de abajo es un ejemplo. Se verá como C:\Program Files\Zaaheen\zaaheen.exe, que es donde Zaaheen suele instalarse en Windows. Si instalaste Zaaheen en otro lugar, como otra unidad u otra carpeta, tu ruta es distinta y esta no funcionará. Copia tu ruta exacta desde Zaaheen: Agents, Connect an app, Cursor Desktop y luego Copy.

En Cursor Desktop, elige Customize en la barra de la izquierda y luego MCPs. Baja hasta el final, elige + New MCP server y pega esto. Guárdalo:

{
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

La ruta de abajo es un ejemplo. Se verá como /Applications/Zaaheen.app/Contents/MacOS/zaaheen, que es donde Zaaheen suele instalarse en un Mac. Si instalaste Zaaheen en otro lugar, tu ruta es distinta y esta no funcionará. Copia tu ruta exacta desde Zaaheen: Agents, Connect an app, Cursor Desktop y luego Copy.

En Cursor Desktop, elige Customize en la barra de la izquierda y luego MCPs. Baja hasta el final, elige + New MCP server y pega esto. Guárdalo:

{
  "mcpServers": {
    "zaaheen": {
      "command": "/Applications/Zaaheen.app/Contents/MacOS/zaaheen",
      "args": ["mcp", "serve"]
    }
  }
}

Paso 2: Comprueba que está conectado

Cursor › Customize

En Cursor Desktop, elige Customize en la barra de la izquierda y luego MCPs. zaaheen aparece ahí, conectado.
