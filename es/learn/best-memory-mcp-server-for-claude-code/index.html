¿Qué servidor MCP de memoria usar con Claude Code?

No hay uno que sea el mejor; depende de para qué quieras la memoria. Para una memoria gratis y sencilla solo para Claude Code, te sirven el servidor de referencia de Anthropic o mcp-memory-service. Para notas que puedas leer tú mismo, Basic Memory. Para una sola memoria cifrada que Claude Code comparta con Cursor, ChatGPT y Claude Desktop, sin Python ni archivos de configuración, para eso creamos Zaaheen.

Por Zaaheen · Actualizado el 22 de octubre de 2026

Qué añade un servidor de memoria a Claude Code

Claude Code ya recuerda dentro de un proyecto: CLAUDE.md, que escribes tú, y la memoria automática, que escribe él, las dos guardadas en tu computadora para ese repositorio (documentación de Anthropic). Un servidor de memoria añade una memoria en la que Claude Code puede buscar y guardar en todos tus proyectos y, según el servidor, que otras apps de IA también pueden usar.

Las opciones

El servidor de memoria de referencia de Anthropic

Se describe a sí mismo como "A basic implementation of persistent memory using a local knowledge graph" (una implementación básica de memoria persistente usando un grafo de conocimiento local). Es gratis y con licencia MIT. Añades un comando npx a la configuración de tu app, o lo ejecutas con Docker, y guarda todo en un archivo llamado memory.jsonl (su página de GitHub). Su página no menciona el cifrado.

mcp-memory-service

Un servidor de memoria gratis y de código abierto que se instala con pip. Puede guardar los recuerdos de forma local en SQLite, o en Cloudflare y otros backends, y menciona Claude Code, Cursor, Codex y Claude Desktop entre las apps con las que funciona (su página de GitHub). Tiene muchas opciones, algo que va bien a quien le gusta configurar sus herramientas.

Basic Memory

Escribe los recuerdos como notas Markdown sencillas que puedes abrir y editar. La versión local es gratis y necesita Python 3.12 o superior, instalado con uv o, en un Mac, con Homebrew (su guía de inicio rápido). Una versión Cloud alojada cuesta desde 15 USD al mes (sitio de Basic Memory).

Mem0

Una memoria alojada: su servidor MCP funciona del lado de Mem0 y tus recuerdos viven en tu cuenta de Mem0, con un plan Hobby gratis (documentación de Mem0). Buena opción si quieres la memoria en internet y no en una computadora.

Zaaheen

La nuestra. Una app para Windows y Mac que guarda una sola memoria cifrada en tu computadora. Para Claude Code copias un comando de la pestaña Agents de Zaaheen y lo ejecutas una vez; a partir de ahí está en todos tus proyectos (paso a paso). La misma memoria se comparte con Cursor, Claude Desktop, la app de ChatGPT, Codex y otras apps.

Cuánto cuesta un año

Las opciones gratis son gratis. Lo que pagas con Zaaheen es no tener que configurar nada más que un comando, el cifrado en tu computadora y una sola memoria que comparten tus otras apps de IA.

Cómo elegir

Si solo usas Claude Code y te gusta configurar cosas, empieza con uno de los servidores gratis. Si quieres leer y editar tu memoria como notas, usa Basic Memory. Si quieres la memoria en internet, mira Mem0. Si también usas Cursor, Claude Desktop o ChatGPT y quieres que todos compartan lo que aprende Claude Code, cifrado en tu propia computadora, prueba Zaaheen gratis durante 30 días.

Dónde se queda corto Zaaheen: solo Windows y Mac con chips de Apple, sin Linux; una computadora, todavía sin sincronización; no es de código abierto; no hay plan gratis después de la prueba.
