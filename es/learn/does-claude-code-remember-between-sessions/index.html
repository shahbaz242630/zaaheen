¿Claude Code recuerda entre sesiones?

Sí, dentro de un proyecto y en una computadora. Claude Code empieza cada sesión con un contexto nuevo y luego carga dos tipos de notas: los archivos CLAUDE.md que escribes tú y la memoria automática que escribe él mismo. Ninguna de las dos te sigue a la carpeta de memoria de otro proyecto, a otra computadora ni a otra app de IA.

Por Zaaheen · Actualizado el 22 de octubre de 2026

Qué recuerda Claude Code

La documentación de Anthropic (How Claude remembers your project, en inglés) describe dos formas en que el conocimiento pasa de una sesión a la siguiente:

  • Los archivos CLAUDE.md son instrucciones que escribes tú: cómo compilar el proyecto, reglas que seguir, cosas que evitar. Pueden estar en el proyecto, en tu carpeta de usuario o definirlas tu organización, y todos los que aplican se cargan al empezar cada sesión.
  • La memoria automática (auto memory) son notas que Claude Code escribe para sí mismo mientras trabajas: tus correcciones, tus preferencias y lo que ha aprendido sobre el proyecto. Cuando dices "recuerda que las pruebas necesitan una base de datos local", va aquí.

Los dos son archivos de texto que puedes abrir y editar. En una sesión, /memory los muestra, los abre y activa o desactiva la memoria automática.

Qué se carga al empezar cada sesión

La memoria automática vive en una carpeta para cada proyecto, ~/.claude/projects/<project>/memory/, con un archivo llamado MEMORY.md como índice. Al empezar una sesión solo se cargan las primeras 200 líneas o 25KB de ese índice, lo que llegue antes. Las notas detalladas están en archivos de temas aparte que Claude Code abre cuando los necesita.

Así que Claude Code sí recuerda, pero la mayor parte de lo que sabe la consulta cuando la necesita en lugar de leerla cada vez. Mantener el índice corto, con una línea por recuerdo, es lo que mantiene a la vista lo importante. Anthropic sugiere que cada CLAUDE.md tenga menos de 200 líneas por la misma razón.

Lo que no se lleva

La documentación es clara sobre los límites:

  • Una carpeta de memoria por proyecto. Todos los worktrees de un repositorio la comparten, pero otro repositorio tiene la suya, así que lo que Claude Code aprendió sobre ti en un proyecto no está en el siguiente.
  • Una computadora. La memoria automática es local de cada máquina y no se comparte entre máquinas ni entornos en la nube.
  • Una app. Cursor, Codex, ChatGPT y Claude Desktop no leen la carpeta de memoria de Claude Code.

Para las reglas del proyecto, eso es justo lo correcto: van con el proyecto. Para los datos sobre ti, como cómo te gustan las respuestas, las herramientas que prefieres o en qué estás trabajando este mes, significa contárselo otra vez a cada proyecto y a cada app.

Que te recuerde entre proyectos y apps

Una memoria que vive fuera de Claude Code cubre ese hueco. Claude Code puede conectarse a herramientas mediante MCP, la forma estándar en que las apps de IA se conectan a herramientas y datos, así que puede guardar datos sobre ti en una memoria que pueden leer todos tus proyectos y tus otras apps de IA.
