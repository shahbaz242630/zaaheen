Cómo tener una sola memoria en Claude Code, Cursor y Codex

Claude Code, Cursor y Codex guardan cada uno su propia memoria, y ninguno lee la de los otros. Pon las reglas del proyecto en un archivo AGENTS.md, que los tres pueden leer, y guarda lo que es cierto sobre ti en una sola memoria compartida a la que se conectan los tres.

Por Zaaheen · Actualizado el 22 de octubre de 2026

Qué guarda cada uno

Según la documentación de cada empresa:

AppSu propia memoria¿Compartida con los otros?
Claude CodeArchivos CLAUDE.md que escribes tú, más la memoria automática que escribe él, en una carpeta para cada proyecto en tu computadora (Anthropic)No
CursorReglas del proyecto en .cursor/rules, reglas de usuario para todos tus proyectos y AGENTS.md (Cursor)No
CodexAGENTS.md, más recuerdos que puede escribir en ~/.codex/memories/, desactivados hasta que los activas (OpenAI)No, ni siquiera con ChatGPT

Así que una preferencia que le enseñas a Claude Code el lunes es nueva para Cursor el martes y para Codex el miércoles. Los desarrolladores que alternan entre ellos acaban repitiendo lo mismo tres veces, o manteniendo tres archivos sincronizados a mano.

Reglas del proyecto: un AGENTS.md para los tres

Para las reglas del propio proyecto, como cómo compilarlo, cómo ejecutar las pruebas y qué convenciones seguir, ahora hay una respuesta sencilla: AGENTS.md. Cursor lo lee como uno de sus tipos de reglas. OpenAI sugiere guardar en él las indicaciones que Codex debe seguir siempre. Y Claude Code lo lee como las instrucciones del proyecto cuando el proyecto no tiene CLAUDE.md (desde la versión 2.1.277).

Un solo archivo en el repositorio, guardado junto al código, y las tres herramientas parten de las mismas reglas. Si ya tienes un CLAUDE.md, la documentación de Anthropic explica cómo hacer que apunte a AGENTS.md para que los dos nunca se contradigan.

Lo que saben de ti: una sola memoria compartida

AGENTS.md no es el lugar para los datos sobre ti. No forman parte del proyecto, cambian y sirven en todos los proyectos, no en uno. Ahí entra una memoria compartida: una memoria fuera de las tres herramientas a la que cada una se conecta mediante MCP, la forma estándar en que las apps de IA se conectan a herramientas y datos.

Zaaheen es una de esas memorias, para Windows y Mac, guardada y cifrada en tu propia computadora. Cada herramienta se conecta una vez: Claude Code con un comando, Cursor con un enlace de instalación y Codex con unas pocas líneas en su archivo de configuración (Claude Code, Cursor, Codex). Después, lo que cualquiera de ellas guarde sobre ti, las otras lo pueden recordar.

Nuestra prueba

Lo probamos con Cursor leyendo una memoria compartida que tenía unos 15 datos sobre una persona, guardados antes por otra app. Las preguntas eran de las que harías de verdad, y dos estaban pensadas para hacerlo fallar: una sobre algo que la memoria no tenía y una pregunta trampa.

Las cinco respuestas fueron correctas, incluidas las dos en que la respuesta correcta era "no". Para una memoria, esa segunda parte importa tanto como la primera: una app que se inventa una respuesta es peor que una que dice que no lo sabe.
