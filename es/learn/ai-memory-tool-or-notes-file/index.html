¿Necesitas una herramienta de memoria para la IA, o basta un archivo de notas?

Para un proyecto en una herramienta de programación, un archivo de notas como CLAUDE.md o AGENTS.md suele ser todo lo que necesitas. Deja de bastar cuando usas varias apps de IA, cuando los datos son sobre ti y no sobre el proyecto, o cuando el archivo crece más de lo que la app lee al empezar.

Por Zaaheen · Actualizado el 22 de octubre de 2026

Cuándo basta un archivo de notas

Muchos desarrolladores dicen que un simple archivo de notas es toda la memoria que necesita una IA, y para algunos trabajos tienen razón. Un archivo es gratis, puedes leer cada palabra, vive en el proyecto junto al código y no le pasa nada que tú no hayas escrito.

Un archivo es la herramienta adecuada cuando:

  • Usas una app de IA, casi siempre en un proyecto.
  • Lo que necesita saber es sobre el proyecto: cómo compilarlo, cómo probarlo, qué evitar.
  • Lo mantienes corto y al día tú mismo.

Claude Code lee CLAUDE.md, Cursor lee sus reglas, y los tres, Claude Code, Cursor y Codex, pueden leer un AGENTS.md. Para las reglas del proyecto, un AGENTS.md guardado junto al código es difícil de superar.

Dónde se queda corto un archivo

  • Cada app lee un archivo distinto, o ninguno. Las apps de chat de ChatGPT y Claude no leen los archivos de notas de tus herramientas de programación; su propia memoria vive en la cuenta de cada empresa.
  • Los datos sobre ti no pertenecen a un solo proyecto. Cómo te gustan las respuestas, las herramientas que prefieres, en qué trabajas este mes: si los pones en el archivo de un repositorio, el siguiente proyecto no los tiene.
  • Alguien tiene que escribirlo. Un archivo solo sabe lo que tú, o la app, se acordó de añadir, y mantener sincronizados los archivos de tres apps es una tarea que se acaba descuidando.
  • Al empezar solo se lee una parte. Anthropic sugiere que cada CLAUDE.md tenga menos de 200 líneas, y al empezar una sesión solo carga las primeras 200 líneas o 25KB del índice de memoria de Claude Code (documentación de Anthropic). Más allá de eso, un archivo más largo cuesta más y se sigue menos.
