Which memory MCP server should you use with Claude Code?

There is no single best one; it depends on what you want the memory for. For a free, simple memory just for Claude Code, Anthropic's own reference server or mcp-memory-service will do. For notes you can read yourself, Basic Memory. For one encrypted memory that Claude Code shares with Cursor, ChatGPT and Claude Desktop, with no Python or config files, that's what we built Zaaheen for.

By Zaaheen · Last updated 13 October 2026

What a memory server adds to Claude Code

Claude Code already remembers within a project: CLAUDE.md, which you write, and auto memory, which it writes, both kept on your computer for that one repository (Anthropic's docs). A memory server adds a memory that Claude Code can search and save to across all your projects, and, depending on the server, one that other AI apps can use too.

The options

Anthropic's reference memory server

Described in its own words as "A basic implementation of persistent memory using a local knowledge graph". It is free and MIT licensed. You add one npx command to your app's settings, or run it with Docker, and it stores everything in a file called memory.jsonl (its GitHub page). Its page doesn't mention encryption.

mcp-memory-service

A free, open-source memory server you install with pip. It can store memories locally in SQLite or in Cloudflare and other backends, and names Claude Code, Cursor, Codex and Claude Desktop among the apps it works with (its GitHub page). It has many options, which suits people who like to configure their tools.

Basic Memory

Writes memories as plain Markdown notes you can open and edit. The local version is free and needs Python 3.12 or higher, installed with uv or, on a Mac, Homebrew (its quickstart). A hosted Cloud version starts at $15 a month (Basic Memory's site).

Mem0

A hosted memory: its MCP server runs on Mem0's side and your memories live in your Mem0 account, with a free Hobby plan (Mem0's docs). Good if you want the memory online rather than on one computer.

Zaaheen

Ours. A Windows and Mac app that keeps one memory encrypted on your computer. For Claude Code you copy one command from Zaaheen's Agents tab and run it once; after that it is there in every project (step by step). The same memory is shared with Cursor, Claude Desktop, the ChatGPT app, Codex and other apps.

How to choose

If you only use Claude Code and like setting things up, start with one of the free servers. If you want to read and edit your memory as notes, use Basic Memory. If you want the memory online, look at Mem0.
