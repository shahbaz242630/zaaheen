How to share memory between ChatGPT and Claude

ChatGPT and Claude each keep their own memory, and neither can read the other's. You can copy what ChatGPT knows into Claude by hand, use Claude's memory import once, or connect both apps to one shared memory so a fact you tell either app is there in both.

By Zaaheen · Last updated 6 October 2026

Why ChatGPT and Claude don't share memory

Both apps can remember you. ChatGPT keeps saved memories and can refer back to your past chats; you manage them under Settings, Personalization, Memory (OpenAI's help page). Claude builds a memory from your chats, with a separate memory for each project; you manage it under Settings, Memory (Anthropic's help page).

Each memory lives in that company's account, on that company's servers, and there is no link between the two. So the preferences ChatGPT learned over months mean nothing to Claude on the first day, and the reverse. People describe it the same way again and again: re-explaining who they are, what they're working on and how they like answers, every time they switch.

There are three ways around it. They differ in effort and in one thing that matters a lot: whether they keep working after the first day.

Option 1: copy and paste

The simplest way costs nothing:

  1. In ChatGPT, ask: "List everything you remember about me, as short bullet points."
  2. Read the list and remove anything you don't want to carry over.
  3. In Claude, start a chat, paste the list and say "Please remember these about me."

It works for a handful of facts. The catch is that it is a snapshot. Anything you tell ChatGPT tomorrow stays in ChatGPT until you copy again, and the two memories drift apart from there.

Option 2: Claude's memory import

Claude has a tool built for this move (Anthropic's help page). It is on the Free, Pro, Max and Team plans, on the web and in Claude Desktop:

  1. In Claude, open Settings, then Memory, and choose Start import. Claude gives you a prompt to copy.
  2. Paste that prompt into ChatGPT. It writes out what it remembers about you.
  3. Copy ChatGPT's answer back into Claude's box and choose Add to memory.

It is quick, but Anthropic is clear about the limits: the import is experimental, it can take up to 24 hours to show up, and Claude keeps mainly work-related details, so some personal ones may not carry over. It also only goes one way, once. OpenAI's memory help page describes no import from other apps, and a fact you tell ChatGPT after the import never reaches Claude.

Option 3: one memory both apps use

The third way stops moving memories around. Instead of two memories, one inside each app, you keep one memory outside both, and connect each app to it. Whatever you tell ChatGPT is saved there, and Claude reads it from there, today and next month.

Apps connect to tools like this through MCP, the standard way AI apps plug into tools and data. Zaaheen is one such memory: an app for Windows and Mac that keeps your memories encrypted on your own computer, where ChatGPT, Claude and your other connected AI apps can save to it and look things up. Setting it up for these two apps:

  • Claude Desktop: Zaaheen's Agents tab saves an extension you install in Claude (step by step). It works in Claude's Chat and Cowork.
  • ChatGPT: the ChatGPT app for your computer, where you add Zaaheen under Settings, Plugins, MCP, and use it in a Work or Codex chat (step by step). ChatGPT's Chat mode, and ChatGPT in a web browser, can't connect to apps on your computer.

Both apps keep using their own memory too, and won't always think of a shared one by themselves. Add this line to each app's instructions so they do: "When I ask you to remember something, save it in Zaaheen. Before answering anything about me, my preferences, my work or my plans, also check my Zaaheen memory, even when your own memory has nothing."

To bring over what ChatGPT already knows, ask ChatGPT once, after connecting: "Save everything you remember about me to Zaaheen." From then on there is nothing left to copy.

We tested a shared memory ourselves. Five AI apps on one Windows computer were connected to the same Zaaheen memory, and we asked eight questions about the person, such as their favourite tea, their favourite city and when they like meetings, mostly in a different app from the one that saved the answer.

Every app that reached the memory gave the right answer. Half the time the app checked by itself; the other times it answered from its own memory first and needed "check Zaaheen". That is why the line above, in each app's instructions, matters.

If you only use the two apps now and then, copying a short list once may be all you need. If you're moving from ChatGPT to Claude for good, Claude's import is made for that. If you use both, every week, a shared memory is the one that doesn't go stale.
