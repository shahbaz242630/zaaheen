So verbindest du Claude Desktop mit Zaaheen

Öffne in Zaaheen den Tab Agents, wähle Connect an app, dann Claude Desktop und Save the extension, und installiere sie in Claude. Füge danach eine Zeile zu den Anweisungen von Claude hinzu, damit es Zaaheen nutzt. Es funktioniert in Chat und Cowork von Claude.

Bitte folge allen 3 Schritten. Lässt du einen aus, nutzt Claude Desktop Zaaheen vielleicht nicht.

Schritt 1A: Der schnelle Weg

Zaaheen › Agents

Zaaheen speichert eine kleine Claude-Erweiterung, und Claude fragt dich, ob du sie installieren willst.

  1. Öffne in Zaaheen den Tab Agents und wähle Connect an app.
  2. Wähle Claude Desktop, dann Save the extension.
  3. Zaaheen hat die Erweiterung in deinem Ordner Downloads gespeichert. Öffne in Claude Settings, dann Extensions, dann Advanced settings, dann Install Extension, und wähle "Zaaheen for Claude.mcpb".

Öffnet sich stattdessen Claude und fragt, ob du Zaaheen installieren willst, klick auf Install, und es ist verbunden.

Schritt 1B: Oder selbst hinzufügen

Claude › Settings

So bekommst du die Einstellung am einfachsten richtig: Öffne in Zaaheen Agents, wähle Connect an app, dann Claude Desktop. Dort steht die Einstellung mit dem Pfad dieses Computers, mit einem Copy-Knopf. Nutze die Copy-Knöpfe, statt Text von Hand zu markieren.

Der Pfad unten ist ein Beispiel. Er sieht etwa so aus: C:\Program Files\Zaaheen\zaaheen.exe. Dort installiert sich Zaaheen unter Windows normalerweise. Hast du Zaaheen woanders installiert, etwa auf einem anderen Laufwerk oder in einem anderen Ordner, ist dein Pfad anders, und dieser hier funktioniert nicht. Kopiere deinen genauen Pfad aus Zaaheen: Agents, Connect an app, Claude Desktop, dann Copy.

Öffne in Claude Settings, dann Developer, dann Edit Config. Füge das hier in die Datei ein, die es dir zeigt, speichere sie, beende Claude und öffne es wieder:

{
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

Der Pfad unten ist ein Beispiel. Er sieht etwa so aus: /Applications/Zaaheen.app/Contents/MacOS/zaaheen. Dort installiert sich Zaaheen auf dem Mac normalerweise. Hast du Zaaheen woanders installiert, ist dein Pfad anders, und dieser hier funktioniert nicht. Kopiere deinen genauen Pfad aus Zaaheen: Agents, Connect an app, Claude Desktop, dann Copy.

Öffne in Claude Settings, dann Developer, dann Edit Config. Füge das hier in die Datei ein, die es dir zeigt, speichere sie, beende Claude und öffne es wieder:

{
  "mcpServers": {
    "zaaheen": {
      "command": "/Applications/Zaaheen.app/Contents/MacOS/zaaheen",
      "args": ["mcp", "serve"]
    }
  }
}

Schritt 2: Prüfen, ob es verbunden ist

Claude › Settings

Öffne in Claude Settings, dann Extensions. Dort steht Zaaheen und ist eingeschaltet. Hast du es selbst hinzugefügt (Schritt 1B), steht es stattdessen unter Settings, dann Developer.

Schritt 3: Sag Claude Desktop, dass es Zaaheen nutzen soll (nicht auslassen)

Claude › Settings

Claude sieht zuerst in seinem eigenen Gedächtnis nach. Öffne in Claude Settings, dann Account, und füge diese Zeile unter Instructions for Claude hinzu:

When I ask you to remember something, save it in Zaaheen. Before answering anything about me, my preferences, my work or my plans, also check my Zaaheen memory, even when your own memory has nothing.
