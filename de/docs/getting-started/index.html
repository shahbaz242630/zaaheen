So installierst du Zaaheen und richtest es ein

Lade Zaaheen für Windows oder Mac herunter, installiere es und wähle dann Begin set up. Die Einrichtung dauert etwa drei Minuten: Du meldest dich in der App an, was deine kostenlose Testphase von 30 Tagen startet (keine Karte nötig), wählst, wo deine Erinnerungen liegen, und verbindest deine erste KI-App.

Bevor du anfängst

Windows oder Mac

Zaaheen 0.3.5 ist für Windows (64-Bit), getestet unter Windows 11, und für Macs mit Apple-Chip, M1 oder neuer, getestet unter macOS 26. Für Linux und Handys gibt es es noch nicht.

Die App ist auf Englisch. Diese Anleitung nennt Knöpfe und Menüs deshalb so, wie du sie in der App siehst.

Für Windows herunterladen Für Mac herunterladen

Installieren

Windows oder Mac

Unter Windows öffnest du das heruntergeladene Installationsprogramm. Unterwegs siehst du vielleicht bis zu drei Fragen, und jede ist normal:

  • Microsoft Edge sagt, die Datei "isn't commonly downloaded". Das Installationsprogramm ist neu, deshalb hat Edge es noch nicht oft gesehen. Wähle die drei Punkte neben dem Download, dann Keep, Show more und Keep anyway. Chrome fragt nicht.
  • Windows sagt, der Herausgeber sei unbekannt. Das Installationsprogramm ist noch nicht code-signiert; die Signatur kommt später. Wähle More info, dann Run anyway.
  • Windows fragt nach Administratorrechten. Zaaheen wird für alle auf dem Computer installiert, deshalb fragt Windows einmal. Zum Ausführen braucht es danach keine Administratorrechte.

Auf dem Mac öffnest du das heruntergeladene Disk-Image, ziehst Zaaheen in den Ordner Programme (Applications) und öffnest Zaaheen dann von dort. Zaaheen läuft nur von dort.

  • Dein Mac fragt, ob er eine aus dem Internet geladene App öffnen soll. Er nennt den Entwickler. Die Mac-App ist von Apple signiert und geprüft. Wähle Open.
  • Dein Mac fragt vielleicht, ob Zaaheen deinen Schlüsselbund nutzen darf. Dort liegt der Schlüssel zu deinen Erinnerungen. Wähle Always Allow.

Um deinen Download zu prüfen, vergleiche seinen Fingerabdruck (SHA-256) mit dem unten. Weichen sie ab, lösche die Datei und lade sie erneut von dieser Website herunter.

  • Windows (Zaaheen_0.3.5_x64.msi): c58c6f0e0ad17ccb1e41855a1e36cfc73b81f9a72e2b3ecd9c106600904d91c0. Führe in PowerShell Get-FileHash "$HOME\Downloads\Zaaheen_0.3.5_x64.msi" aus.
  • Mac (Zaaheen_0.3.5_aarch64.dmg): 615e00a5d5ba9bdef26a64ff321847550ac46b4c3683a2ecdf585c8550d8b41a. Führe im Terminal shasum -a 256 ~/Downloads/Zaaheen_0.3.5_aarch64.dmg aus.

Einrichten

Begin set up

Öffne Zaaheen und wähle Begin set up. Es führt dich durch fünf Schritte:

  1. Dein Konto. Wähle Create an account oder Sign in. Dabei öffnet sich dein Webbrowser. Deine kostenlose Testphase von 30 Tagen beginnt, wenn du dich zum ersten Mal in der Zaaheen-App anmeldest, und du brauchst keine Karte. Die Anmeldung teilt deine Erinnerungen nie mit uns.
  2. Wo deine Erinnerungen liegen. Der übliche Ort passt für die meisten. Du kannst ihn später in Settings mit Move my memories… ändern.
  3. Deine erste KI-App. Wähle die App, die du nutzt, und folge den Schritten, oder wähle I'll connect one later.
  4. Deine erste Erinnerung. Erzähl Zaaheen etwas, das deine KI-Apps über dich wissen sollten, und wähle dann Keep this memory oder Skip for now.
  5. Aufräumen. Zaaheen räumt dein Gedächtnis jede Nacht von selbst auf, außer du wählst Not now, dann Finish setup.

Beim ersten Mal lädt Zaaheen außerdem herunter, was es zum Durchsuchen deiner Erinnerungen braucht. Das passiert im Hintergrund, und du kannst Zaaheen währenddessen schon nutzen.

Agents

  • Claude Code verbinden
  • Cursor verbinden
  • ChatGPT verbinden
  • Codex verbinden
  • Antigravity verbinden
  • Andere KI-Apps verbinden
