So verbindest du Antigravity mit Zaaheen

Öffne die Einstellungsdatei von Antigravity, mcp_config.json, füge die Einstellung aus dem Tab Agents in Zaaheen ein, speichere und starte Antigravity neu. Prüf dann, ob Zaaheen unter den MCP-Tools mit einem grünen Kreis erscheint.

Bitte folge beiden Schritten. Lässt du einen aus, nutzt Antigravity Zaaheen vielleicht nicht.

Schritt 1: Selbst hinzufügen

Antigravity › mcp_config.json

So bekommst du die Einstellung am einfachsten richtig: Öffne in Zaaheen Agents, wähle Connect an app, dann Antigravity. Dort steht die Einstellung mit dem Pfad dieses Computers, mit einem Copy-Knopf. Nutze die Copy-Knöpfe, statt Text von Hand zu markieren.

Der Pfad unten ist ein Beispiel. Er sieht etwa so aus: C:\Program Files\Zaaheen\zaaheen.exe. Dort installiert sich Zaaheen unter Windows normalerweise. Hast du Zaaheen woanders installiert, etwa auf einem anderen Laufwerk oder in einem anderen Ordner, ist dein Pfad anders, und dieser hier funktioniert nicht. Kopiere deinen genauen Pfad aus Zaaheen: Agents, Connect an app, Antigravity, dann Copy.

Öffne zuerst seine Einstellungsdatei in Notepad (dem Windows-Editor): Drück Windows und R gleichzeitig, füge die Zeile für dein Antigravity ein und drück Enter.

Antigravity-App

notepad %USERPROFILE%\.gemini\config\mcp_config.json

Antigravity IDE

notepad %USERPROFILE%\.gemini\antigravity\mcp_config.json

Füge dann das hier ein. Stehen in der Datei schon andere Apps, füge den zaaheen-Teil daneben ein. Speichere sie, schließ Antigravity vollständig und öffne es wieder:

{
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

Der Pfad unten ist ein Beispiel. Er sieht etwa so aus: /Applications/Zaaheen.app/Contents/MacOS/zaaheen. Dort installiert sich Zaaheen auf dem Mac normalerweise. Hast du Zaaheen woanders installiert, ist dein Pfad anders, und dieser hier funktioniert nicht. Kopiere deinen genauen Pfad aus Zaaheen: Agents, Connect an app, Antigravity, dann Copy.

Öffne zuerst seine Einstellungsdatei in TextEdit: Öffne das Terminal, füge die Zeile für dein Antigravity ein und drück Return.

Antigravity-App

mkdir -p ~/.gemini/config && touch ~/.gemini/config/mcp_config.json && open -e ~/.gemini/config/mcp_config.json

Antigravity IDE

mkdir -p ~/.gemini/antigravity && touch ~/.gemini/antigravity/mcp_config.json && open -e ~/.gemini/antigravity/mcp_config.json

Füge dann das hier ein. Stehen in der Datei schon andere Apps, füge den zaaheen-Teil daneben ein. Speichere sie, schließ Antigravity vollständig und öffne es wieder:

{
  "mcpServers": {
    "zaaheen": {
      "command": "/Applications/Zaaheen.app/Contents/MacOS/zaaheen",
      "args": ["mcp", "serve"]
    }
  }
}

Schritt 2: Prüfen, ob es verbunden ist

Antigravity › mcp_config.json

Öffne in Antigravity Settings, dann Customization. Klick unter Token usage neben MCP tools auf Show breakdown. Dort steht Zaaheen mit einem grünen Kreis.
