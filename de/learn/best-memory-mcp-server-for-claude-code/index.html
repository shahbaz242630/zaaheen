Welchen Gedächtnis-MCP-Server solltest du mit Claude Code nutzen?

Den einen besten gibt es nicht; es hängt davon ab, wofür du das Gedächtnis willst. Für ein kostenloses, einfaches Gedächtnis nur für Claude Code reicht der Referenzserver von Anthropic oder mcp-memory-service. Für Notizen, die du selbst lesen kannst, Basic Memory. Für ein verschlüsseltes Gedächtnis, das Claude Code mit Cursor, ChatGPT und Claude Desktop teilt, ohne Python oder Konfigurationsdateien, haben wir Zaaheen gebaut.

Von Zaaheen · Aktualisiert am 22. Oktober 2026

Was ein Gedächtnis-Server Claude Code bringt

Claude Code erinnert sich bereits innerhalb eines Projekts: an CLAUDE.md, die du schreibst, und an Auto Memory, die es selbst schreibt, beide auf deinem Computer für dieses eine Repository gespeichert (Dokumentation von Anthropic). Ein Gedächtnis-Server fügt ein Gedächtnis hinzu, das Claude Code über alle deine Projekte hinweg durchsuchen und befüllen kann, und je nach Server eines, das auch andere KI-Apps nutzen können.

Die Optionen

Der Referenz-Gedächtnis-Server von Anthropic

Nach eigener Beschreibung „A basic implementation of persistent memory using a local knowledge graph“ (eine einfache Umsetzung eines dauerhaften Gedächtnisses mit einem lokalen Wissensgraphen). Er ist kostenlos und MIT-lizenziert. Du fügst einen npx-Befehl in die Einstellungen deiner App ein oder startest ihn mit Docker, und er speichert alles in einer Datei namens memory.jsonl (GitHub-Seite). Verschlüsselung wird auf der Seite nicht erwähnt.

mcp-memory-service

Ein kostenloser Open-Source-Gedächtnis-Server, den du mit pip installierst. Er kann Erinnerungen lokal in SQLite oder in Cloudflare und anderen Backends speichern und nennt Claude Code, Cursor, Codex und Claude Desktop unter den Apps, mit denen er funktioniert (GitHub-Seite). Er hat viele Optionen, was Leuten liegt, die ihre Werkzeuge gern selbst konfigurieren.

Basic Memory

Schreibt Erinnerungen als einfache Markdown-Notizen, die du öffnen und bearbeiten kannst. Die lokale Version ist kostenlos und braucht Python 3.12 oder neuer, installiert mit uv oder auf dem Mac mit Homebrew (Schnellstart). Eine gehostete Cloud-Version kostet ab 15 USD pro Monat (Website von Basic Memory).

Mem0

Ein gehostetes Gedächtnis: Sein MCP-Server läuft bei Mem0, und deine Erinnerungen liegen in deinem Mem0-Konto, mit einem kostenlosen Hobby-Tarif (Dokumentation von Mem0). Gut, wenn du das Gedächtnis lieber online statt auf einem Computer haben willst.

Zaaheen

Unseres. Eine App für Windows und Mac, die ein Gedächtnis verschlüsselt auf deinem Computer aufbewahrt. Für Claude Code kopierst du einen Befehl aus dem Tab Agents in Zaaheen und führst ihn einmal aus; danach ist es in jedem Projekt da (Schritt für Schritt). Dasselbe Gedächtnis teilen sich Cursor, Claude Desktop, die ChatGPT-App, Codex und andere Apps.

Was ein Jahr kostet

Die kostenlosen Optionen sind kostenlos. Wofür du bei Zaaheen bezahlst: keine Einrichtung über einen Befehl hinaus, Verschlüsselung auf deinem Computer und ein Gedächtnis, das deine anderen KI-Apps teilen.

Wie du wählst

Wenn du nur Claude Code nutzt und Dinge gern selbst einrichtest, fang mit einem der kostenlosen Server an. Wenn du dein Gedächtnis als Notizen lesen und bearbeiten willst, nimm Basic Memory. Wenn du das Gedächtnis online haben willst, sieh dir Mem0 an. Wenn du auch Cursor, Claude Desktop oder ChatGPT nutzt und willst, dass sie alle teilen, was Claude Code lernt, verschlüsselt auf deinem eigenen Computer, teste Zaaheen 30 Tage kostenlos.

Wo Zaaheen nicht mithält: nur Windows und Macs mit Apple-Chips, kein Linux; ein Computer, noch ohne Synchronisierung; nicht Open Source; kein kostenloser Tarif nach der Testphase.
