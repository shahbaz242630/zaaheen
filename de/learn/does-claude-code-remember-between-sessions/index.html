Erinnert sich Claude Code zwischen Sitzungen?

Ja, innerhalb eines Projekts auf einem Computer. Claude Code beginnt jede Sitzung mit einem frischen Kontext und lädt dann zwei Arten von Notizen: die CLAUDE.md-Dateien, die du schreibst, und die Auto Memory, die es selbst schreibt. Keine davon folgt dir in den Gedächtnisordner eines anderen Projekts, auf einen anderen Computer oder in eine andere KI-App.

Von Zaaheen · Aktualisiert am 22. Oktober 2026

Was Claude Code sich merkt

Die Dokumentation von Anthropic (How Claude remembers your project) beschreibt zwei Wege, auf denen Wissen von einer Sitzung zur nächsten kommt:

  • CLAUDE.md-Dateien sind Anweisungen, die du schreibst: wie das Projekt gebaut wird, welche Regeln gelten, was zu vermeiden ist. Sie können im Projekt liegen, in deinem Benutzerordner oder von deiner Organisation vorgegeben sein, und jede, die zutrifft, wird zu Beginn jeder Sitzung geladen.
  • Auto Memory sind Notizen, die Claude Code beim Arbeiten für sich selbst schreibt: deine Korrekturen, deine Vorlieben und was es über das Projekt gelernt hat. Wenn du sagst „merk dir, dass die Tests eine lokale Datenbank brauchen“, landet das hier.

Beides sind einfache Textdateien, die du öffnen und bearbeiten kannst. In einer Sitzung listet /memory sie auf, öffnet sie und schaltet Auto Memory ein oder aus.

Was zu Beginn jeder Sitzung geladen wird

Auto Memory liegt in einem Ordner pro Projekt, ~/.claude/projects/<project>/memory/, mit einer Datei namens MEMORY.md als Inhaltsverzeichnis. Nur die ersten 200 Zeilen oder 25 KB dieses Verzeichnisses, je nachdem, was zuerst erreicht ist, werden beim Start einer Sitzung geladen. Die ausführlichen Notizen stehen in separaten Themendateien, die Claude Code öffnet, wenn es sie braucht.

Wir bauen Zaaheen jeden Tag mit Claude Code, also haben wir das Gedächtnis unseres eigenen Projekts nach fünf Monaten Sitzungen gemessen:

Claude Code erinnert sich also, aber das meiste, was es weiß, wird bei Bedarf nachgeschlagen statt jedes Mal gelesen. Ein kurzes Verzeichnis mit einer Zeile pro Erinnerung sorgt dafür, dass das Wichtige im Blick bleibt. Aus demselben Grund empfiehlt Anthropic, jede CLAUDE.md unter 200 Zeilen zu halten.

Was es nicht mitnimmt

Die Dokumentation ist bei den Grenzen eindeutig:

  • Ein Gedächtnisordner pro Projekt. Alle Worktrees eines Repositorys teilen ihn, aber ein anderes Repository hat seinen eigenen. Was Claude Code in einem Projekt über dich gelernt hat, ist im nächsten also nicht da.
  • Ein Computer. Auto Memory ist lokal auf dem Gerät und wird nicht zwischen Geräten oder Cloud-Umgebungen geteilt.
  • Eine App. Cursor, Codex, ChatGPT und Claude Desktop lesen den Gedächtnisordner von Claude Code nicht.

Für Projektregeln ist das genau richtig: Sie gehören zum Projekt. Für Fakten über dich, etwa wie du Antworten magst, welche Werkzeuge du bevorzugst oder woran du diesen Monat arbeitest, heißt es aber, es jedem Projekt und jeder App neu zu erzählen.

Über Projekte und Apps hinweg an dich erinnern

Ein Gedächtnis außerhalb von Claude Code schließt diese Lücke. Claude Code kann sich über MCP mit Werkzeugen verbinden, dem Standardweg, über den KI-Apps an Werkzeuge und Daten andocken. So kann es Fakten über dich in einem Gedächtnis speichern, das jedes Projekt und deine anderen KI-Apps lesen können.

Zaaheen ist so ein Gedächtnis, für Windows und Mac. Du verbindest Claude Code einmal, mit einem Befehl aus dem Tab Agents in Zaaheen, und danach ist es in jedem Claude-Code-Projekt verfügbar (Schritt für Schritt). Deine Erinnerungen bleiben verschlüsselt auf deinem eigenen Computer.

Eine gute Aufteilung: Projektregeln in CLAUDE.md, Auto Memory für das, was Claude Code über das Projekt lernt, und was über dich gilt in einem gemeinsamen Gedächtnis, das jede App liest.

Zaaheen ist ein gemeinsames privates Gedächtnis für Claude, ChatGPT, Cursor und deine anderen KI-Apps, verschlüsselt auf deinem eigenen Computer. 30 Tage kostenlos, ohne Karte.
