So nutzt du ein Gedächtnis für Claude Code, Cursor und Codex

Claude Code, Cursor und Codex haben jeweils ihr eigenes Gedächtnis, und keines liest das der anderen. Leg Projektregeln in eine AGENTS.md-Datei, die alle drei lesen können, und bewahre, was über dich gilt, in einem gemeinsamen Gedächtnis auf, mit dem sich alle drei verbinden.

Von Zaaheen · Aktualisiert am 22. Oktober 2026

Was jedes Werkzeug speichert

Laut der eigenen Dokumentation der Unternehmen:

AppIhr eigenes GedächtnisMit den anderen geteilt?
Claude CodeCLAUDE.md-Dateien, die du schreibst, plus Auto Memory, die es selbst schreibt, in einem Ordner pro Projekt auf deinem Computer (Anthropic)Nein
CursorProjektregeln in .cursor/rules, Benutzerregeln für alle deine Projekte und AGENTS.md (Cursor)Nein

Eine Vorliebe, die du Claude Code am Montag beibringst, ist für Cursor am Dienstag neu und für Codex am Mittwoch auch. Entwickler, die zwischen ihnen wechseln, wiederholen dieselben Dinge dreimal oder halten drei Dateien von Hand auf demselben Stand.

Projektregeln: eine AGENTS.md für alle drei

Für Regeln zum Projekt selbst, etwa wie es gebaut wird, wie die Tests laufen und welche Konventionen gelten, gibt es inzwischen eine einfache Antwort: AGENTS.md. Cursor liest sie als eine seiner Regelarten. OpenAI empfiehlt, die Vorgaben, an die sich Codex immer halten muss, dort abzulegen. Und Claude Code liest sie als Anweisungen des Projekts, wenn das Projekt keine CLAUDE.md hat (ab Version 2.1.277).

Eine Datei im Repository, zusammen mit dem Code eingecheckt, und alle drei Werkzeuge starten mit denselben Regeln. Wenn du schon eine CLAUDE.md hast, zeigt die Dokumentation von Anthropic, wie du sie auf AGENTS.md verweisen lässt, damit sich die beiden nie widersprechen.

Was sie über dich wissen: ein gemeinsames Gedächtnis

AGENTS.md ist der falsche Ort für Fakten über dich. Sie gehören nicht zum Projekt, sie ändern sich, und sie gehören in jedes Projekt, nicht nur in eines. Hier kommt ein gemeinsames Gedächtnis ins Spiel: ein Gedächtnis außerhalb aller drei Werkzeuge, mit dem sich jedes über MCP verbindet, den Standardweg, über den KI-Apps an Werkzeuge und Daten andocken.

Zaaheen ist so ein Gedächtnis, für Windows und Mac, verschlüsselt auf deinem eigenen Computer. Jedes Werkzeug wird einmal verbunden: Claude Code mit einem Befehl, Cursor mit einem Installationslink und Codex mit ein paar Zeilen in seiner Einstellungsdatei (Claude Code, Cursor, Codex). Danach kann jedes von ihnen abrufen, was ein anderes über dich gespeichert hat.

Unser Test

Wir haben das mit Cursor ausprobiert, das ein gemeinsames Gedächtnis mit etwa 15 Fakten über eine Person las, die zuvor eine andere App gespeichert hatte. Die Fragen waren solche, die man wirklich stellen würde, und zwei sollten Cursor aufs Glatteis führen: eine zu etwas, das nicht im Gedächtnis stand, und eine Fangfrage.

Alle fünf Antworten waren richtig, auch die beiden, bei denen die richtige Antwort „nein“ war. Bei einem Gedächtnis zählt dieser zweite Teil so viel wie der erste: Eine App, die eine Antwort erfindet, ist schlechter als eine, die sagt, dass sie es nicht weiß.

Zaaheen ist ein gemeinsames privates Gedächtnis für Claude, ChatGPT, Cursor und deine anderen KI-Apps, verschlüsselt auf deinem eigenen Computer. 30 Tage kostenlos, ohne Karte.
