    Keeping a copy of your memories

    Your copy

    Your memories live only on your computer, locked with a key that Windows or macOS keeps for your user account on that computer. We hold no copy, so we cannot restore them for you.

    You lose your memories if the computer is lost, stolen or damaged, if the drive fails, if you delete the memory folder, or if your user account or the computer's operating system (Windows or macOS) is removed or reinstalled. Copying the memory folder does not protect you against this, because the copy cannot be opened without the key.

    Download my memories saves everything you have kept as one file that you can read. Save one regularly and keep it somewhere safe. The file is not encrypted, so anyone who gets it can read it. Zaaheen cannot load that file back in today.

    Delete everything is permanent. It destroys the key and the memory files on that computer, and no one, including us, can undo it. It does not delete files you saved with Download my memories; delete those yourself if you no longer want them.

    What Zaaheen's AI can get wrong

    On your computer

    Zaaheen uses AI on your computer to find memories and, if you turn it on, to tidy them. Search can miss a memory or return one that does not fit the question. Tidying merges near duplicates, rewords memories when it merges them, settles facts that contradict each other in favour of the newer one, and writes short summaries. It keeps the older version rather than erasing it, but it can get a merge, a summary or a choice between two facts wrong.

    Your AI apps can also save a memory that is wrong or that you did not mean to keep. Check anything important before you act on it, and correct or delete a memory that is wrong. Zaaheen stores and finds facts. It does not give medical, legal, financial or other professional advice, and nothing it returns is advice.
