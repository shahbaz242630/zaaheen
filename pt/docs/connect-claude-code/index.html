Como conectar o Claude Code ao Zaaheen

Em um terminal, rode um único comando da aba Agents do Zaaheen. O Zaaheen fica disponível em todos os projetos do Claude Code.

Siga os dois passos. Se você pular um, o Claude Code pode não usar o Zaaheen.

Passo 1: Adicione você mesmo

Terminal

O jeito mais fácil de acertar a configuração: no Zaaheen, abra Agents, escolha Connect an app e depois Claude Code. Ele mostra a configuração com o caminho deste computador, com um botão Copy. Use os botões Copy em vez de selecionar o texto à mão.

O caminho abaixo é um exemplo. Ele vai ser parecido com C:\Program Files\Zaaheen\zaaheen.exe, que é onde o Zaaheen costuma ser instalado no Windows. Se você instalou o Zaaheen em outro lugar, como outra unidade ou pasta, seu caminho é diferente, e este não vai funcionar. Copie o seu caminho exato no Zaaheen: Agents, Connect an app, Claude Code e depois Copy.

Em um terminal, rode isto uma vez. O Zaaheen fica disponível em todos os projetos do Claude Code:

claude mcp add --transport stdio --scope user zaaheen -- "C:\Program Files\Zaaheen\zaaheen.exe" mcp serve

O caminho abaixo é um exemplo. Ele vai ser parecido com /Applications/Zaaheen.app/Contents/MacOS/zaaheen, que é onde o Zaaheen costuma ser instalado no Mac. Se você instalou o Zaaheen em outro lugar, seu caminho é diferente, e este não vai funcionar. Copie o seu caminho exato no Zaaheen: Agents, Connect an app, Claude Code e depois Copy.

Em um terminal, rode isto uma vez. O Zaaheen fica disponível em todos os projetos do Claude Code:

claude mcp add --transport stdio --scope user zaaheen -- "/Applications/Zaaheen.app/Contents/MacOS/zaaheen" mcp serve

Passo 2: Confira se está conectado

Terminal

Em um terminal, rode claude mcp list. O Zaaheen aparece como conectado.

Como usar

Claude Code

Pergunte ao Claude Code sobre você, suas preferências ou seu trabalho, ou peça que ele consulte sua memória do Zaaheen. O que ele salvar ali, seus outros apps de IA conectados também podem usar.
