Como conectar o Antigravity ao Zaaheen

Abra o arquivo de configurações do Antigravity, mcp_config.json, cole a configuração do Zaaheen que aparece na aba Agents do Zaaheen, salve e reinicie o Antigravity. Depois confira se o Zaaheen aparece com um círculo verde em MCP tools.

Siga os dois passos. Se você pular um, o Antigravity pode não usar o Zaaheen.

Passo 1: Adicione você mesmo

Antigravity › mcp_config.json

O jeito mais fácil de acertar a configuração: no Zaaheen, abra Agents, escolha Connect an app e depois Antigravity. Ele mostra a configuração com o caminho deste computador, com um botão Copy. Use os botões Copy em vez de selecionar o texto à mão.

O caminho abaixo é um exemplo. Ele vai ser parecido com C:\Program Files\Zaaheen\zaaheen.exe, que é onde o Zaaheen costuma ser instalado no Windows. Se você instalou o Zaaheen em outro lugar, como outra unidade ou pasta, seu caminho é diferente, e este não vai funcionar. Copie o seu caminho exato no Zaaheen: Agents, Connect an app, Antigravity e depois Copy.

Primeiro abra o arquivo de configurações dele no Bloco de Notas (Notepad): pressione Windows e R juntos, cole a linha do seu Antigravity e pressione Enter.

Antigravity app

notepad %USERPROFILE%\.gemini\config\mcp_config.json

Antigravity IDE

notepad %USERPROFILE%\.gemini\antigravity\mcp_config.json

Depois cole isto. Se o arquivo já lista outros apps, adicione a parte do zaaheen ao lado deles. Salve, feche o Antigravity por completo e abra de novo:

{
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

O caminho abaixo é um exemplo. Ele vai ser parecido com /Applications/Zaaheen.app/Contents/MacOS/zaaheen, que é onde o Zaaheen costuma ser instalado no Mac. Se você instalou o Zaaheen em outro lugar, seu caminho é diferente, e este não vai funcionar. Copie o seu caminho exato no Zaaheen: Agents, Connect an app, Antigravity e depois Copy.

Primeiro abra o arquivo de configurações dele no TextEdit: abra o Terminal, cole a linha do seu Antigravity e pressione Return.

Antigravity app

mkdir -p ~/.gemini/config && touch ~/.gemini/config/mcp_config.json && open -e ~/.gemini/config/mcp_config.json

Antigravity IDE

mkdir -p ~/.gemini/antigravity && touch ~/.gemini/antigravity/mcp_config.json && open -e ~/.gemini/antigravity/mcp_config.json

Depois cole isto. Se o arquivo já lista outros apps, adicione a parte do zaaheen ao lado deles. Salve, feche o Antigravity por completo e abra de novo:

{
  "mcpServers": {
    "zaaheen": {
      "command": "/Applications/Zaaheen.app/Contents/MacOS/zaaheen",
      "args": ["mcp", "serve"]
    }
  }
}

Passo 2: Confira se está conectado

Antigravity › mcp_config.json

No Antigravity, abra Settings e depois Customization. Em Token usage, ao lado de MCP tools, clique em Show breakdown. O Zaaheen aparece com um círculo verde.
