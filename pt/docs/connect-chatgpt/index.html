Como conectar o ChatGPT ao Zaaheen

No ChatGPT Desktop, abra Settings, depois Plugins, depois MCP, e adicione um servidor MCP chamado Zaaheen com o comando da aba Agents do Zaaheen e os argumentos mcp e serve. Depois use o Zaaheen em um chat de Work ou de Codex.

Siga os 3 passos. Se você pular um, o ChatGPT Desktop pode não usar o Zaaheen.

Passo 1: Adicione você mesmo

ChatGPT › Settings

O jeito mais fácil de acertar a configuração: no Zaaheen, abra Agents, escolha Connect an app e depois ChatGPT Desktop. Ele mostra a configuração com o caminho deste computador, com um botão Copy. Use os botões Copy em vez de selecionar o texto à mão.

O caminho abaixo é um exemplo. Ele vai ser parecido com C:\Program Files\Zaaheen\zaaheen.exe, que é onde o Zaaheen costuma ser instalado no Windows. Se você instalou o Zaaheen em outro lugar, como outra unidade ou pasta, seu caminho é diferente, e este não vai funcionar. Copie o seu caminho exato no Zaaheen: Agents, Connect an app, ChatGPT Desktop e depois Copy.

1. No ChatGPT Desktop, abra Settings, depois Plugins no alto, e escolha MCP. Abra o menu suspenso no canto superior direito e escolha Add MCP server.

2. Name (nome)

Zaaheen

3. Command: cole exatamente assim, sem espaço antes

C:\Program Files\Zaaheen\zaaheen.exe

4. Arguments: digite mcp na primeira caixa

mcp

5. Clique em + para adicionar uma segunda caixa e digite serve nela

serve

6. Clique em Save. Depois feche o ChatGPT por completo (no Windows, também pelo ícone ao lado do relógio) e abra de novo. Use o Zaaheen em um chat de Work ou de Codex: o modo Chat do ChatGPT não consegue se conectar a apps do seu computador.

O caminho abaixo é um exemplo. Ele vai ser parecido com /Applications/Zaaheen.app/Contents/MacOS/zaaheen, que é onde o Zaaheen costuma ser instalado no Mac. Se você instalou o Zaaheen em outro lugar, seu caminho é diferente, e este não vai funcionar. Copie o seu caminho exato no Zaaheen: Agents, Connect an app, ChatGPT Desktop e depois Copy.

Passo 2: Confira se está conectado

ChatGPT › Settings

No ChatGPT, abra Settings, depois Plugins, depois MCP. O Zaaheen aparece ali, ativado.

Passo 3: Diga ao ChatGPT Desktop para usar o Zaaheen (não pule este passo)

ChatGPT › Settings

O ChatGPT olha primeiro na própria memória. No ChatGPT, abra Settings, depois Personalization, depois Custom instructions, e adicione esta linha:

When I ask you to remember something, save it in Zaaheen. Before answering anything about me, my preferences, my work or my plans, also check my Zaaheen memory, even when your own memory has nothing.
