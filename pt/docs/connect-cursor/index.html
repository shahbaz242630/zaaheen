Como conectar o Cursor ao Zaaheen

No Zaaheen, abra a aba Agents, escolha Connect an app, depois Cursor Desktop e Connect it for me. O Cursor abre e pede para você instalar o Zaaheen, o que pode levar até um minuto: clique em Install. O Cursor IDE passa a usar a mesma conexão.

Usa o Cursor IDE? Conecte o Zaaheen aqui, pelo Cursor Desktop: o IDE não tem configurações de MCP próprias e usa as que você define no Cursor Desktop, então conectar uma vez basta para os dois.

Siga os dois passos. Se você pular um, o Cursor Desktop pode não usar o Zaaheen.

Passo 1A: O jeito rápido

Zaaheen › Agents

O Zaaheen abre o Cursor, e o Cursor pede para você instalar o Zaaheen. O Cursor pode levar até um minuto para abrir e mostrar a caixa Install, então espere por ela e depois clique em Install.

  1. No Zaaheen, abra a aba Agents e escolha Connect an app.
  2. Escolha Cursor Desktop e depois Connect it for me.
  3. Esperando o Cursor abrir e mostrar a caixa Install. Isso pode levar até um minuto.
  4. O Cursor deve estar mostrando agora a caixa Install. Clique em Install e pronto, está conectado. Se nada apareceu, vá para a janela do Cursor: a caixa pode estar atrás desta.

Passo 1B: Ou adicione você mesmo

Cursor › Customize

O jeito mais fácil de acertar a configuração: no Zaaheen, abra Agents, escolha Connect an app e depois Cursor Desktop. Ele mostra a configuração com o caminho deste computador, com um botão Copy. Use os botões Copy em vez de selecionar o texto à mão.

O caminho abaixo é um exemplo. Ele vai ser parecido com C:\Program Files\Zaaheen\zaaheen.exe, que é onde o Zaaheen costuma ser instalado no Windows. Se você instalou o Zaaheen em outro lugar, como outra unidade ou pasta, seu caminho é diferente, e este não vai funcionar. Copie o seu caminho exato no Zaaheen: Agents, Connect an app, Cursor Desktop e depois Copy.

No Cursor Desktop, escolha Customize na barra da esquerda e depois MCPs. Role até o fim, escolha + New MCP server e cole isto. Salve:

{
  "mcpServers": {
    "zaaheen": {
      "command": "C:\\Program Files\\Zaaheen\\zaaheen.exe",
      "args": ["mcp", "serve"]
    }
  }
}

O caminho abaixo é um exemplo. Ele vai ser parecido com /Applications/Zaaheen.app/Contents/MacOS/zaaheen, que é onde o Zaaheen costuma ser instalado no Mac. Se você instalou o Zaaheen em outro lugar, seu caminho é diferente, e este não vai funcionar. Copie o seu caminho exato no Zaaheen: Agents, Connect an app, Cursor Desktop e depois Copy.

No Cursor Desktop, escolha Customize na barra da esquerda e depois MCPs. Role até o fim, escolha + New MCP server e cole isto. Salve:

{
  "mcpServers": {
    "zaaheen": {
      "command": "/Applications/Zaaheen.app/Contents/MacOS/zaaheen",
      "args": ["mcp", "serve"]
    }
  }
}

Passo 2: Confira se está conectado

Cursor › Customize

No Cursor Desktop, escolha Customize na barra da esquerda e depois MCPs. O zaaheen aparece ali, conectado.
