Como instalar e configurar o Zaaheen

Baixe o Zaaheen para Windows ou Mac e instale, depois escolha Begin set up. A configuração leva cerca de três minutos: você entra pelo app, o que inicia seu teste grátis de 30 dias (sem precisar de cartão), escolhe onde suas memórias ficam e conecta seu primeiro app de IA.

Antes de começar

Windows ou Mac

O Zaaheen 0.3.8 é para Windows de 64 bits, testado no Windows 11, e para Macs com chip da Apple, M1 ou mais recente, testado no macOS 26. Ainda não está disponível para Linux nem para celulares.

O app está em inglês.

Baixar para Windows Baixar para Mac

Instalar

Windows ou Mac

No Windows, abra o instalador que você baixou. Podem aparecer até três perguntas no caminho, e todas são esperadas:

  • O Microsoft Edge diz que o arquivo "isn't commonly downloaded" (não é baixado com frequência). O instalador é novo, então o Edge ainda não o viu muitas vezes. Escolha os três pontos ao lado do download, depois Keep, Show more e Keep anyway. O Chrome não pergunta.
  • O Windows diz que o editor é desconhecido. O instalador ainda não tem assinatura de código; a assinatura vem depois. Escolha More info e depois Run anyway.
  • O Windows pede permissão de administrador. O Zaaheen é instalado para todos no computador, então o Windows pergunta uma vez. Ele não precisa de direitos de administrador para rodar depois.

No Mac, abra a imagem de disco que você baixou, arraste o Zaaheen para a pasta Aplicativos (Applications) e abra o Zaaheen a partir dela. O Zaaheen só roda dali.

Não encontra Aplicativos? Abra o Finder (o rosto azul e branco à esquerda do Dock) e escolha Aplicativos na barra lateral à esquerda. Ou, com o Finder aberto, pressione Shift-Command-A.

  • Seu Mac pergunta se deve abrir um app baixado da internet. Ele mostra o nome do desenvolvedor. O app para Mac é assinado e verificado pela Apple. Escolha Open.
  • Seu Mac pode perguntar se o Zaaheen pode usar suas chaves (keychain). É ali que fica a chave das suas memórias. Escolha Always Allow.

Para conferir seu download, compare a impressão digital dele (SHA-256) com a de baixo. Se forem diferentes, apague o arquivo e baixe de novo deste site.

  • Windows (Zaaheen_0.3.8_x64.msi): 50147fc643b9e8d4e743c60acbd5c21a34e6672d211534d7add288f28c20d0e4. No PowerShell, rode Get-FileHash "$HOME\Downloads\Zaaheen_0.3.8_x64.msi".
  • Mac (Zaaheen_0.3.8_aarch64.dmg): ae694d3d02ef0d38b591c70db3b4710673f3549c5c9a0d6956d145ce39ed12ab. No Terminal, rode shasum -a 256 ~/Downloads/Zaaheen_0.3.8_aarch64.dmg.

Configurar

Begin set up

Abra o Zaaheen e escolha Begin set up. Ele guia você por cinco passos:

  1. Sua conta. Escolha Create an account ou Sign in. Isso abre seu navegador. Seu teste grátis de 30 dias começa na primeira vez que você entra pelo app do Zaaheen, e não precisa de cartão. Entrar na conta nunca compartilha suas memórias conosco.
  2. Onde guardar suas memórias. O lugar padrão serve para a maioria das pessoas. Você pode mudar depois em Settings, com Move my memories….
  3. Seu primeiro app de IA. Escolha o app que você usa e siga os passos, ou escolha I'll connect one later.
  4. Sua primeira memória. Conte ao Zaaheen algo que seus apps de IA devem saber sobre você e escolha Keep this memory, ou Skip for now.
  5. Arrumação. O Zaaheen arruma sua memória sozinho toda noite, a menos que você escolha Not now; depois escolha Finish setup.

Na primeira vez, o Zaaheen também baixa o que precisa para pesquisar suas memórias. Ele faz isso em segundo plano, e você pode usar o Zaaheen enquanto termina.
