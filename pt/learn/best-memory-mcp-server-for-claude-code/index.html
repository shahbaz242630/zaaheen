Qual servidor MCP de memória usar com o Claude Code?

Não existe um único melhor; depende de para que você quer a memória. Para uma memória grátis e simples só para o Claude Code, o servidor de referência da própria Anthropic ou o mcp-memory-service resolvem. Para anotações que você mesmo pode ler, o Basic Memory. Para uma memória criptografada que o Claude Code compartilha com o Cursor, o ChatGPT e o Claude Desktop, sem Python nem arquivos de configuração, foi para isso que criamos o Zaaheen.

Por Zaaheen · Atualizado em 22 de outubro de 2026

O que um servidor de memória acrescenta ao Claude Code

O Claude Code já lembra dentro de um projeto: o CLAUDE.md, que você escreve, e a auto memory, que ele escreve, as duas guardadas no seu computador para aquele repositório (documentação da Anthropic). Um servidor de memória acrescenta uma memória que o Claude Code pode pesquisar e na qual pode salvar em todos os seus projetos e, dependendo do servidor, que outros apps de IA também podem usar.

As opções

O servidor de memória de referência da Anthropic

Descrito nas próprias palavras como "A basic implementation of persistent memory using a local knowledge graph" (uma implementação básica de memória persistente usando um grafo de conhecimento local). É grátis e tem licença MIT. Você adiciona um comando npx às configurações do seu app, ou o roda com Docker, e ele guarda tudo em um arquivo chamado memory.jsonl (página no GitHub). A página dele não menciona criptografia.

mcp-memory-service

Um servidor de memória grátis e de código aberto que você instala com pip. Ele pode guardar memórias localmente em SQLite ou no Cloudflare e em outros backends, e cita Claude Code, Cursor, Codex e Claude Desktop entre os apps com que funciona (página no GitHub). Tem muitas opções, o que agrada a quem gosta de configurar as próprias ferramentas.

Basic Memory

Escreve memórias como anotações simples em Markdown que você pode abrir e editar. A versão local é grátis e precisa do Python 3.12 ou superior, instalada com uv ou, no Mac, com Homebrew (guia de início rápido). Uma versão Cloud hospedada começa em US$ 15 por mês (site do Basic Memory).

Mem0

Uma memória hospedada: o servidor MCP dele roda do lado do Mem0 e suas memórias ficam na sua conta Mem0, com um plano Hobby grátis (documentação do Mem0). Bom se você quer a memória online, e não em um computador.

Zaaheen

O nosso. Um app para Windows e Mac que guarda uma memória única criptografada no seu computador. Para o Claude Code, você copia um comando da aba Agents do Zaaheen e o roda uma vez; depois disso, ele está presente em todos os projetos (passo a passo). A mesma memória é compartilhada com o Cursor, o Claude Desktop, o app do ChatGPT, o Codex e outros apps.

Quanto custa um ano

As opções grátis são grátis. O que você paga com o Zaaheen é nenhuma configuração além de um comando, criptografia no seu computador e uma memória que seus outros apps de IA compartilham.

Como escolher

Se você só usa o Claude Code e gosta de configurar as coisas, comece com um dos servidores grátis. Se quer ler e editar sua memória como anotações, use o Basic Memory. Se quer a memória online, veja o Mem0. Se você também usa o Cursor, o Claude Desktop ou o ChatGPT e quer que todos compartilhem o que o Claude Code aprende, criptografado no seu próprio computador, experimente o Zaaheen grátis por 30 dias.

Onde o Zaaheen fica devendo: só Windows e Macs com chip da Apple, sem Linux; um computador, ainda sem sincronização; não é de código aberto; não há plano grátis depois do teste.
