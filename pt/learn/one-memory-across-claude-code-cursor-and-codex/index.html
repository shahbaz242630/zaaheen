Como manter uma única memória no Claude Code, no Cursor e no Codex

O Claude Code, o Cursor e o Codex têm cada um a sua própria memória, e nenhum lê a dos outros. Coloque as regras do projeto em um único arquivo AGENTS.md, que os três conseguem ler, e mantenha o que é verdade sobre você em uma memória compartilhada à qual os três se conectam.

Por Zaaheen · Atualizado em 22 de outubro de 2026

O que cada um guarda

Segundo a documentação de cada empresa:

AppA própria memóriaCompartilhada com os outros?
Claude CodeArquivos CLAUDE.md que você escreve, mais a auto memory que ele escreve, em uma pasta para cada projeto no seu computador (Anthropic)Não
CursorRegras de projeto em .cursor/rules, regras de usuário para todos os seus projetos e AGENTS.md (Cursor)Não
CodexAGENTS.md, mais memórias que ele pode escrever em ~/.codex/memories/, desligadas até você ativá-las (OpenAI)Não, nem mesmo com o ChatGPT

Então uma preferência que você ensina ao Claude Code na segunda-feira é novidade para o Cursor na terça e para o Codex na quarta. Desenvolvedores que alternam entre eles acabam repetindo as mesmas coisas três vezes, ou mantendo três arquivos sincronizados à mão.

Regras do projeto: um AGENTS.md para os três

Para regras sobre o próprio projeto, como compilar, como rodar os testes e as convenções a seguir, agora existe uma resposta simples: AGENTS.md. O Cursor o lê como um dos seus tipos de regra. A OpenAI sugere manter nele as orientações que o Codex deve sempre seguir. E o Claude Code o lê como as instruções do projeto quando o projeto não tem CLAUDE.md (a partir da versão 2.1.277).

Um arquivo no repositório, versionado junto com o código, e as três ferramentas começam das mesmas regras. Se você já tem um CLAUDE.md, a documentação da Anthropic mostra como apontá-lo para o AGENTS.md, para que os dois nunca discordem.

O que eles sabem sobre você: uma memória compartilhada

O AGENTS.md é o lugar errado para fatos sobre você. Eles não fazem parte do projeto, mudam e pertencem a todos os projetos, não a um só. É aí que entra uma memória compartilhada: uma memória fora das três ferramentas, à qual cada uma se conecta por meio do MCP, o jeito padrão de os apps de IA se ligarem a ferramentas e dados.

O Zaaheen é uma memória desse tipo, para Windows e Mac, guardada e criptografada no seu próprio computador. Cada ferramenta é conectada uma vez: o Claude Code com um comando, o Cursor com um link de instalação e o Codex com algumas linhas no arquivo de configuração dele (Claude Code, Cursor, Codex). Depois disso, o que qualquer um deles salvar sobre você, os outros conseguem recuperar.

Nosso teste

Testamos isso com o Cursor lendo uma memória compartilhada que guardava uns 15 fatos sobre uma pessoa, salvos antes por outro app. As perguntas eram do tipo que você faria de verdade, e duas foram feitas para pegá-lo no erro: uma sobre algo que a memória não guardava e uma pergunta capciosa.

As cinco respostas estavam certas, inclusive as duas em que a resposta certa era "não". Para uma memória, essa segunda parte importa tanto quanto a primeira: um app que inventa uma resposta é pior do que um que diz que não sabe.

O Zaaheen é uma única memória privada para o Claude, o ChatGPT, o Cursor e seus outros apps de IA, guardada e criptografada no seu próprio computador. 30 dias grátis, sem cartão.
