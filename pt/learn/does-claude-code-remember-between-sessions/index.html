O Claude Code lembra entre uma sessão e outra?

Sim, dentro de um projeto, em um computador. O Claude Code começa cada sessão com um contexto novo e depois carrega dois tipos de anotação: os arquivos CLAUDE.md que você escreve e a auto memory que ele mesmo escreve. Nenhum dos dois acompanha você até a pasta de memória de outro projeto, outro computador ou outro app de IA.

Por Zaaheen · Atualizado em 22 de outubro de 2026

O que o Claude Code lembra

A documentação da Anthropic (How Claude remembers your project) descreve duas formas de o conhecimento passar de uma sessão para a próxima:

  • Arquivos CLAUDE.md são instruções que você escreve: como compilar o projeto, regras a seguir, coisas a evitar. Eles podem ficar no projeto, na sua pasta de usuário ou ser definidos pela sua organização, e todos os que se aplicam são carregados no início de cada sessão.
  • Auto memory são anotações que o Claude Code escreve para si mesmo enquanto você trabalha: suas correções, preferências e o que ele aprendeu sobre o projeto. Quando você diz "lembre que os testes precisam de um banco de dados local", é para lá que isso vai.

Os dois são arquivos de texto simples que você pode abrir e editar. Em uma sessão, /memory lista esses arquivos, abre cada um e liga ou desliga a auto memory.

O que carrega no início de cada sessão

A auto memory fica em uma pasta para cada projeto, ~/.claude/projects/<project>/memory/, com um arquivo chamado MEMORY.md como índice. Só as primeiras 200 linhas ou 25KB desse índice, o que vier primeiro, são carregadas quando uma sessão começa. As anotações detalhadas ficam em arquivos de tema separados, que o Claude Code abre quando precisa.

O que ele não leva junto

A documentação é clara sobre os limites:

  • Uma pasta de memória por projeto. Todas as worktrees de um repositório compartilham a mesma, mas outro repositório tem a sua, então o que o Claude Code aprendeu sobre você em um projeto não está no seguinte.
  • Um computador. A auto memory é local da máquina e não é compartilhada entre máquinas nem ambientes na nuvem.
  • Um app. O Cursor, o Codex, o ChatGPT e o Claude Desktop não leem a pasta de memória do Claude Code.

Para regras do projeto, isso está exatamente certo: elas pertencem ao projeto. Para fatos sobre você, como você gosta das respostas, as ferramentas que prefere ou no que está trabalhando este mês, significa contar tudo de novo a cada projeto e a cada app.

Lembrar de você entre projetos e apps

Uma memória que fica fora do Claude Code preenche essa lacuna. O Claude Code consegue se conectar a ferramentas por meio do MCP, o jeito padrão de os apps de IA se ligarem a ferramentas e dados, então ele pode salvar fatos sobre você em uma memória que todos os projetos, e seus outros apps de IA, conseguem ler.

O Zaaheen é uma memória desse tipo, para Windows e Mac. Você conecta o Claude Code uma vez, com um comando da aba Agents do Zaaheen, e ele passa a estar disponível em todos os projetos do Claude Code (passo a passo). Suas memórias ficam criptografadas no seu próprio computador.

Uma boa divisão: deixe as regras do projeto no CLAUDE.md, deixe a auto memory guardar o que o Claude Code aprende sobre o projeto e mantenha o que é verdade sobre você em uma memória compartilhada que todos os apps leem.

O Zaaheen é uma única memória privada para o Claude, o ChatGPT, o Cursor e seus outros apps de IA, guardada e criptografada no seu próprio computador. 30 dias grátis, sem cartão.
