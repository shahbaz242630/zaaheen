# From download to uninstall, step by step

The whole life of Zaaheen on a computer, in order. Each stage names the topic with the full steps.

## 1. Download and install

zaaheen.com, download for Windows or Mac, open the installer (Windows) or drag Zaaheen into Applications (Mac), answer the expected security questions. Topic `install`.

## 2. Set up (first start)

Click **Begin set up**, then: create an account or sign in (opens the browser; the free trial starts, no card), choose where to keep the memories (the usual place suits most people), connect the first AI app (or later), keep a first memory (or skip), choose automatic tidying, **Finish setup**. Zaaheen downloads its recall engine in the background meanwhile. Topic `install`.

## 3. Connect the AI apps

**Agents** tab, pick each app, follow its numbered steps, restart the app, check it is connected, and add the Zaaheen line to its instructions. Topic `connect`.

## 4. Daily use

- The user talks to their AI apps as usual. The apps save memories into Zaaheen and read from it (topics `memories`, `areas`).
- The user can see, search, add and forget memories in the Zaaheen app's **Memories** tab, organise them into areas in **Boundaries**, and undo deletes in **Recently deleted** (topic `memories`).
- Every night (unless turned off) Zaaheen tidies the memories on its own (topic `consolidation`).

## 5. Closing the window, quitting, reopening

- **Zaaheen has no tray icon.** Closing the Zaaheen window closes the app (on a Mac, quit with Zaaheen menu, Quit, or Command and Q).
- **AI apps keep working with the window closed.** When an AI app uses Zaaheen, it starts Zaaheen's background part by itself; the user does not need the window open. The background part stops on its own a few minutes after the last AI app stops using it.
- **The tidy-up runs even when the window is closed.** On a computer that was asleep at the scheduled time, it catches up the next time the app is opened.
- **Reopening:** open Zaaheen from the Start menu (Windows) or Applications (Mac). It opens on the Memories tab, signed in, with no setup again.

## 6. The account over time

The trial, subscribing, changing plan or card, cancelling, what happens when the trial or subscription ends (nothing is deleted), refunds. Topic `account`.

## 7. Updating

The app shows "A new version of Zaaheen is available." with **Download**. Close Zaaheen and the AI apps, install the new version over the old one, reopen, restart the AI apps. Memories and settings are kept. Topic `update`.

## 8. Moving the memories (another folder or drive)

**Settings**, **Your memories**, **Move my memories…**, choose the folder, **Move them here**. Zaaheen closes, moves them and opens again. Topic `settings`.

## 9. A new computer

Install Zaaheen there and sign in with the same account: the subscription covers every computer. Memories are kept per computer and are not copied between computers (there is no sync, and the app has no way to load a downloaded copy back in). **Download my memories** on the old computer saves a readable copy for the user. Topic `settings`.

## 10. Leaving

Download a copy, erase the memories with **Delete everything**, close the account with **Delete my account** or just cancel the subscription, then uninstall. Topic `uninstall`.

## If anything goes wrong at any stage

Topic `troubleshooting`, and topic `messages` for any message an AI app receives. Help by email: customerservice@zaaheen.com.
