# Updating Zaaheen

## How the user knows a new version is out

When a newer version exists, the top of the Zaaheen app shows the line **"A new version of Zaaheen is available."** with a **Download** button. Zaaheen checks when it starts and once a day. The app does not update itself: the user downloads and installs the new version.

## Which version is installed

Open the Zaaheen app, click **Settings**, then **About Zaaheen**. The **Version** row shows it ("Zaaheen" followed by the version number).

## How to update

Memories are kept: updating replaces the app, not the memories.

1. Click **Download** in the app's "new version" line (it opens the Getting started page), or go to zaaheen.com and download the version for the user's computer.
2. Close the Zaaheen app. Also close the AI apps that use Zaaheen.
3. **Windows:** open the new installer and follow it, exactly as for a first install (topic `install`; the same Edge and "publisher is unknown" questions may appear). It installs over the old version.
   **Mac:** open the new disk image and drag Zaaheen into Applications, choosing **Replace** when asked. Open it from Applications.
4. Open Zaaheen. Check **Settings**, **About Zaaheen**, **Version**.
5. Open the AI apps again. If an AI app says "Zaaheen was updated; restart every app that uses Zaaheen", quit that app completely and open it again.

Nothing needs setting up again: the account, memories, areas, connected apps and tidy-up schedule all stay.

## What changed in each version

The release notes are on zaaheen.com under Documents, **Release notes** (zaaheen.com/docs/release-notes/), newest first, in plain words.

## Why updating matters

Some problems are fixed only in newer versions. When the user meets a problem and the app shows the "new version" line, update first.
